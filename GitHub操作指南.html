GitHub 私有仓库分享 · 操作指南

投研开源包配套文档 ｜ 目标：把 439M 的开源包私有分享给指定朋友 ｜ 全程约 30 分钟
✅ 你的环境已就绪：Git 2.55.0 已安装，无需额外装软件。本指南按命令行操作编写（Git Bash）。

全流程速览：

1 注册/登录 GitHub 账号 → 2 新建私有仓库 → 3 本地推送 439M 内容 → 4 生成访问令牌（认证） → 5 邀请朋友加入 → 朋友下载 ZIP 即完成

第 1 步 · 注册 / 登录 GitHub

1. 打开 https://github.com，右上角 Sign up 注册（邮箱 + 密码 + 用户名），或直接登录已有账号。

2. 注册后到邮箱点验证链接完成激活。用户名建议用拼音或英文（如 zhangsan-invest），后续仓库链接会带上它。

⚠️ 全程建议先开代理（Clash/V2Ray 开启即可）：GitHub 网页在大陆直连不稳定，后面推 439M 大文件更是必须走代理。

第 2 步 · 新建「私有」仓库（网页操作）

1. 登录后点右上角 ＋ → New repository。

2. Repository name 填：invest-expert-pack（可自定义）。

3. 关键：Visibility 必须选 Private（私有）——选 Public 就等于全世界可见，你的原书 PDF 和整理内容会公开。

4. 下方 不要勾选 README / .gitignore / License（本地包里已有，勾了会冲突）。

5. 点 Create repository，会跳到一个"空仓库"页面，先别关，第 3 步要用页面上的仓库地址。

🚫 如果误建成了 Public（公开），进入仓库 → Settings → 拉到最底部 Danger Zone → Change visibility → 改为 Private。公开过的仓库会被搜索引擎收录，改了可见性也不能完全抹除痕迹。

第 3 步 · 本地推送（Git Bash 命令行）

打开 Git Bash（在桌面空白处右键 → Git Bash Here），逐条粘贴以下命令（把 你的账号、仓库名 换成你的实际值）：

cd "C:/Users/Administrator/Desktop/市场研究/投研开源包"

# 首次使用 Git 需先设置身份（只做一次）
git config --global user.name "你的GitHub用户名"
git config --global user.email "你的GitHub邮箱"

# 初始化并提交
git init
git branch -M main
git add .
git commit -m "投研专家团+书籍蒸馏知识库 v1.0"

# 连接远程私有仓库并推送
git remote add origin https://github.com/你的账号/invest-expert-pack.git
git push -u origin main

2. push 时第一次会让你输用户名和密码——密码处填的不是账号密码，而是第 4 步生成的令牌。

3. push 过程中若中途断流（你机器的大文件断流特性），直接重新执行 git push 即可，会自动断点续传，不用重来。

⚠️ 代理必须在 push 前开好：Clash/V2Ray 开启后，Git Bash 会自动读取系统代理（127.0.0.1:7890）。若 push 报 Failed to connect to github.com port 443: Timed out，就是代理没生效，开代理后重试。

第 4 步 · 生成访问令牌（Personal Access Token，一次性）

GitHub 2021 年起不再支持用账号密码 push，必须用令牌或 SSH。令牌生成步骤：

1. GitHub 右上角头像 → Settings → 左侧最底部 Developer settings。

2. Personal access tokens → Tokens (classic) → Generate new token (classic)。

3. Note 随便填（如 push-invest-pack）；Expiration 选 90 天（过期后要重新生成）；勾选 repo 权限（整个 repo 组都要勾上）。

4. 点最底部 Generate token → 生成一串 ghp_xxxx 开头的令牌。只显示这一次，立即复制保存（可临时贴到记事本）。

5. 回 Git Bash push 时：Username 填你的 GitHub 用户名，Password 填这串令牌（粘贴后不显示是正常的，直接回车）。

6. 想省掉以后每次输令牌：执行 git config --global credential.helper store，第一次输过后会记住。

第 5 步 · 邀请朋友（协作者）

1. 打开你的仓库页面：https://github.com/你的账号/invest-expert-pack。

2. 顶部 Settings → 左侧 Collaborators（或 Manage access）。

3. 点 Add people，输入朋友的 GitHub 用户名或注册邮箱 → 选择 Write 权限（只读也够，Read 即可）→ 发送邀请。

4. 朋友接受邀请后即可访问该私有仓库。

💡 朋友没有 GitHub 账号的话，让他先注册一个（免费）。私有仓库的访问是"跟着账号走"的。

第 6 步 · 朋友侧怎么用（不需要装 Git）

朋友不需要安装 Git、不需要懂命令行。两种方式任选：

方式操作适用
网页下载 ZIP打开仓库链接 → 绿色 Code 按钮 → Download ZIP → 解压即得全部内容最省事，推荐
git clone朋友装 Git 后执行 git clone https://github.com/你的账号/invest-expert-pack.git（首次需输入自己的 GitHub 账号+令牌）朋友想持续跟随更新

朋友拿到后按包里 README.md 的三步安装：专家市场放 ~/.workbuddy/plugins/marketplaces/ → 书籍蒸馏放研究目录 → 自配数据源。

常见问题速查

问题解决
push 报 Timed out / 连接失败代理没开或没生效。开 Clash/V2Ray 后重试；Git Bash 会自动读 7890 代理
push 到一半断了直接重跑 git push，断点续传，不用重新 add/commit
push 报 Authentication failed密码处填的是令牌（ghp_ 开头），不是账号密码；令牌过期就重新生成
令牌丢了到 Developer settings → Tokens 里删除旧的，重新生成一个新的
误建成 Public 了仓库 Settings → 底部 Danger Zone → Change visibility → Private
朋友打不开链接朋友还没接受协作者邀请，或没注册账号；先加他为 Collaborator
朋友下载很慢GitHub 下载大文件在国内不稳定，让朋友也开代理；或走网盘补发

最后提醒：私有仓库 ≠ 绝对私密，受邀的朋友理论上仍可转传，所以分发对象限定为信得过的人。原书 PDF 仅供朋友个人学习，README 里已注明不可再传播。
