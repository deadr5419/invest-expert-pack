## 一、框架总纲

凌鹏体系的完整骨架，原书自行给出定义（28章论点7原文锚点）：

> "周期主要站在实体的角度，描述宏观、行业和公司的景气度变化；估值则将实体投射到二级市场，到底要付出多少注码去表达我们对实体的评估；而人性在二级市场被无限放大，加剧了估值乃至景气度的波动。""把握周期、重视估值、控制人性恰恰就是价值投资的内核。"

层级图景（文字勾勒，忠实原书逻辑）：

- **第一层：周期（实体层，定位用）**——回答"现在处于什么位置"。以时代划分（五六年一换玩法、三阶段十七年）、资产兴衰路径（上升五阶段/下跌三阶段）、风格切换三条件、行业周期长度参数（猪3—5年/白酒约10年/银行约20年）为工具，确定宏观、行业、公司景气度所处的阶段。
- **第二层：估值（映射层，测量用）**——回答"这个位置值多少注码"。将实体景气投射为价格标尺：顶部用"100倍组合必回撤"，底部用"代表性指数跌70%出清"与多证据共振；估值是"保护自己最好的方式"，决定胜率与赔率的量化基础。
- **第三层：人性（行为层，纪律用）**——回答"执行中如何不被自己杀死"。贪婪恐惧制造牛熊极致（顶底必有"伟大的故事"）、机构抱团机制延缓出清、规律普及后衰减；对策不是预测而是克制：不逃顶、不抄主跌段、出清区分批买"套"、逆风期坚守框架。
- **三变量的先后权重**：原书未给出"周期定方向、估值定空间、人性定时点"式的一句话公式（此表述不存在于锚点，禁用）；原书的权重表述有两处——①组合构建层面（12章论点7锚点）："那到底什么才是构建组合的主要依据？我认为是商业模式、产业周期和估值"（**而非宏观与市场判断**）；同章拆解稿记载"商业模式……三者中最重要的因素""估值：最重要变量"，两处并存，理解为：商业模式定底仓资格、估值定介入安全边际（此句为框架文档编纂性说明，非原书原文）。②认知论层面（29章）：未来不可测，"好的投资不是未来致胜，而应该是现在就占优"——一切判断转为"研究过往案例得出胜率赔率，让注码站在大数定律上"。
- **框架的元前提**（29章"两次转变"）：①2019年转变——从预测未来转向统计过往（"要求统计过往，那一个严谨的实习生就可以了"）；②2020年转变——以"不变"应"万变"（"追求'不变'，以'不变'应'万变'才是投资的根本"）。三变量即所谓"不变"。

## 二、周期变量（定位层）

### 核心机制：周期如何定位

1. **时代定位**：A股每隔五六年更换主导玩法，2005—2022分三阶段（周期为王/成长致胜/茅宁共舞），上一时代王者大概率陨落、极致压缩的最弱方向可能是下任主角（06章论点1/2/7）。
2. **资产生命周期定位**：主流资产兴起走"被冷落—酝酿—共识—调整—再加速"五阶段（10年一轮），成为"全民偶像"即风险区；下跌走三阶段（估值自然回落→戴维斯双杀→新王崛起资金撤出），第三阶段"明明很便宜，却会进一步下跌"（06章论点3/4/5）。
3. **风格切换定位**：存量切换三条件（暴跌先行/模糊期复辟纠缠/EPS此消彼长）缺一不可；切换是中长期过程，"错过开头完全无所谓"，重仓参与在"确立及扩散强化"阶段（12章论点2/3）；旧风格对利好反应时长递减（一个月→几天→无反应）即时代结束信号（16章论点2(4)）。
4. **行业周期定位**：一切成长皆为周期，用周期长度参数校准；周期由"需求释放的斜率和产能供给"两变量主导，供需时间差制造四阶段景气路径（28章论点1/2）。
5. **环境适用性前置检查**：先判断宏观波动状态再决定是否启用投资时钟/轮动框架（07章论点10）；宏观正确≠市场正确，宏观结论须过微观映射检验（12章论点6）。

## 三、估值变量（测量层）

### 核心机制：估值如何测量

1. **估值终有效**（28章论点4锚点："估值因子在A股非常有效"）：极致趋势只是让钟摆离中点更远、并未阻止回归；低P/B对高P/B策略23年16胜7败、胜率近70%；"贵"是价值投资最大的瑕疵，"估值是保护自己最好的方式"。
2. **顶部测量**：景气度与估值同涨同跌，板块/组合逼近100倍P/E必然回撤——与行业无关、看多逻辑正确也照崩；不猜破灭时点，但承认回撤必然。
3. **底部测量**：代表性指数（基于真实产业浪潮）泡沫破灭跌幅常态70%起，跌70%大概率出清、机会大于风险；叠加多证据共振（利好全面失效的缩量阴跌+估值历史极值+月度连阴极值统计）即历史级机遇。
4. **修复时点测量**：估值修复时点由市场对该板块的偏见深浅决定，而非与景气拐点同步——"价值只会迟到，但不会缺席"；偏见越深修复越滞后（茅台提前、神华滞后4年），决定持有期设计。
5. **测量失效边界**：新王崛起期的旧资产低估值持续失效（ZP-03）；低估值有效前提是"不破产退市的底线价值"；回摆时滞可长达十年级；"股市没有预见性"——下注依据是"估值和位置足够低"而非预见未来（28章论点5）。

### 挂接条目

- ZP-26 → 估值终有效：低P/B胜率近70%、价值因子极致跑输后终回摆，"贵"是最大瑕疵
- ZP-16 → 板块/组合逼近100倍P/E必回撤，与行业无关、逻辑正确也照崩（顶部标尺）
- ZP-20 → 代表性指数跌70%大概率出清，恐慌低位下注风险小于反弹确认后追高（底部标尺）
- ZP-21 → 泡沫破灭主跌段不抄底：半山腰抄底与顶部买入亏损差别不大（禁抄底线）
- ZP-24 → 多证据共振即历史级机遇：底部主动买"套"、不做测试—止损（买入纪律）
- ZP-27 → 修复时点由偏见深浅决定：预判修复时滞、设计持有期
- ZP-03（复挂）→ 低估值失效边界：新吸金主线崛起期，低估值可以更低（与ZP-26书内自洽：机制不同）
- ZP-29（复挂）→ 估值位置是胜率赔率计算的输入："不是股市有预见性，而是估值和位置足够低"

### 调用时机

遇到以下问题时查本节：①某板块/组合估值处什么位置、是否进入泡沫区或出清区；②跌多少算出清、能不能开始买；③低估值策略当前该不该坚持；④买入后估值修复要等多久、持有期怎么设；⑤新主线崛起时旧资产的低估值还能不能信。

## 四、人性变量（行为层）

### 核心机制：人性如何管控

1. **人性永不变**（28章论点6锚点："都不是认知的问题，而是对人性的掌控不足"）：牛熊很大程度由人性制造，顶部极致贪婪（黄金10年/互联网+/永恒赛道）、底部极度恐慌（1664/熔断/2018年底），"恐慌并不比狂热更理性"；对策是读书、复盘、"人须在事上磨"。
2. **故事反向指标**：顶底必有"伟大的故事"，信故事不如信周期、估值和常识；宏大叙事须与估值/周期互验，不单独使用。
3. **制度性行为**：机构抱团机制链（排名考核→抱团→股民变基民闭环→非抱团股抽血），认知基础牢固+抱团深使崩塌显著放缓；日历类机构行为（冬季躁动：考核+假期机制）；规律被普及后衰减、被遗忘后复活——行为类规律本身有生命周期。
4. **执行纪律**：不存在"既享受泡沫又全身而退"的方法（三个知道、一个不知道），靠仓位克制与冗余避险，不依赖逃顶术；流动性是加速器非启动机，不据资金流向构建组合。
5. **坚守是根本**（ZP-33锚点："认知是基础，但人性控制才是根本"）：框架不适期大幅跑输是坚守的代价；"越是人潮涌动，理性的方法反而会收获更大"。

### 挂接条目

- ZP-25 → 顶底必有"伟大的故事"：故事清单+雄文数据陷阱作反向人性指标
- ZP-06 → 抱团机制链：深抱团强势股崩塌放缓勿轻言见底；新机会以抱团瓦解为前提
- ZP-13 → 规律普及衰减、遗忘复活：评估任一有效规律的拥挤度，普及极高时降权
- ZP-15 → 流动性是加速器而非启动机：资金指标只作解释不作前瞻，不据此构建组合
- ZP-17 → 无"既享受泡沫又全身而退"之法：可知级别、可知必灭、不知何时灭→不参与、靠克制
- ZP-33 → 认知只是基础，坚持认知对抗人性才是根本；逆风期跑输是坚守的代价
- ZP-35 → 冬季躁动（公募考核+长假机制）：12月初—春节前胜者组合加仓行情（受ZP-13制约）
- ZP-22（复挂）→ 边缘领涨=反弹非反转：熊市反弹辨识与减仓的行为特征

### 调用时机

遇到以下问题时查本节：①市场出现宏大叙事/一致狂热或恐慌时如何校准；②抱团股跌了很多能不能抄底、新牛市何时具备条件；③某个"有效规律"（日历效应/技术套路）现在还能不能用；④要不要逃顶/抄底/追资金流向；⑤框架逆风期跑输要不要放弃。

## 五、三变量联动决策流程

原书未提供"周期定方向、估值定空间、人性定时点"式单句公式（该表述不存在于任何锚点，禁止引用）。完整决策逻辑链由28章论点7的三变量定义+12章论点7组合依据+29章两次转变拼合，每一环节挂真实条目：

**第0步 环境前置检查（框架适用性）**
- 先判宏观波动状态与规律拥挤度，决定启用哪些工具：ZP-12（时钟仅波动放大期有效）、ZP-13（普及规律降权）。锚点："既无通胀也无通缩，时钟不转了，效果自然就没了""等到全市场遗忘，可能又会有效"。

**第1步 周期定位（实体层：我们在哪）**
- 时代→资产生命周期→风格切换→行业周期逐级定位：ZP-01（时代）、ZP-02/03（五阶段/陨落三阶段）、ZP-04/05（切换确认与旧风格过期）、ZP-07/19/34（行业周期两变量：需求斜率×产能供给）。宏观结论须过微观映射：ZP-14。锚点："把握周期""盛世堆积的产能成为一种负担"。

**第2步 估值测量（映射层：值多少注码）**
- 用位置标尺量化胜率赔率：顶部ZP-16、底部ZP-20/24、修复时滞ZP-27；与ZP-03边界合并判断（有无新吸金主线）。锚点："我们之所以下注，不是因为未来会发生某件事，而是当前的性价比就合适"（28章）。核心转换（29章锚点）："好的投资不是未来致胜，而应该是现在就占优"——用历史案例匹配得出概率分布（如创业板三年半跌70%是"对儿A"），让注码站在大数定律上：ZP-29。

**第3步 人性执行纪律（行为层：怎么下注、怎么活下来）**
- 顶部：不逃顶、靠克制与冗余（ZP-17），故事作反向指标（ZP-25）；主跌段不抄底（ZP-21）；出清区多证据共振主动买"套"、不做测试止损（ZP-24）；大行情面前保持钝感（ZP-29锚点："在大行情面前应该保持钝感，而不是自作聪明，自以为是"）；逆风期坚守框架（ZP-33）。ZP-21与ZP-24构成书内闭环——边界在是否满足出清证据群。

**第4步 事中跟踪与裁决（跟踪状态而非预测事件）**
- 风险收益比而非事件预测：ZP-28（锚点："真正决定行情的是中期的风险收益比""市场无非等一个由头"）；观察点裁决争论：ZP-31；跨市场先行信号：ZP-30（A股反应最慢，债/汇先动）；抱团瓦解状态：ZP-06。

**第5步 组合构建与下注结构**
- 组合三因子"商业模式、产业周期和估值"（而非宏观与市场判断）：ZP-09；市场判断与行业判断分离，非全部高估不因市场看空放弃行业机会：ZP-32；确定性提升下重注（收益=仓位×概率×空间）：ZP-10；时代贝塔过滤：ZP-11；成长内部结构：ZP-08。

**最核心一条决策链（单句版）**：定位周期位置（ZP-01/02/07）→ 极值处估值测量胜率赔率（ZP-16/20/26/29）→ 反人性执行：顶部克制、主跌段空仓、出清区买套（ZP-17/21/24）→ 逆风期坚守（ZP-33）。

## 六、框架失效场景与反面教训

**什么时候这个框架会失灵（原书记载+条目反面教训汇总，不美化）：**

1. **方法论环境失效**：宏观波动收敛期，时钟/轮动框架全部失效——作者亲历2009年前7个月"如有神助"、8月大跌后方法突然失效、此后判断长期错误（ZP-12反面教训）。行为类规律普及后衰减：2015年底作者按春季躁动规律操作"酿成惨剧"（ZP-13反面教训）；冬季躁动拥挤度上升后权重应下调（ZP-35边界）。
2. **低估值失效场景**：新吸金主线崛起期的旧资产，便宜不是买入理由，会跌到"意想不到的低估"（ZP-03）；2012年周期股"估值5年最低"实为珠峰下山、民生银行前夜是10年坏账泥潭（ZP-03/05反面教训）；估值有效前提是底线价值，回摆时滞可达十年级——招行、平安2007—2017十年净利润大增股价不涨（ZP-26边界）。
3. **假切换陷阱**：增量资金普涨不是切换——2014年底蓝筹逆袭是"失败的切换"，2015年风格马上切回（ZP-04反面教训）；"切换不如死守"仅一例、作者明言"尚无法形成统计规律"（12章J03）。
4. **泡沫尾声超预期**："时间和幅度都会超出预期"——2020年3月初看空，市场高位横盘四个月后又再拉升此后才崩盘（ZP-17反面教训）；写入手册的均线逃顶术在股灾中因停牌、限制空头全军覆没；2009.8、2015.6顶部符合经典形态仍"鱼尾多刺"，高手在鱼尾和下跌中段亏钱。
5. **抄底/逃顶两误**：主跌段抄底——100元跌到20元的股票50元抄底"别人亏80%你亏60%差别不大"（ZP-21）；2001年纳指跌71.8%不敢买、反弹50%后重仓入场、最终低点1114点损失很大——低位不买等确认反而更险（ZP-20反面教训）；2021年3月买"牛回头"随后承受第二波、成分股跌50%以上（ZP-22反面教训）。
6. **判断正确的失败**：宏观对、市场错——2009年某大型公募判断"政策不收、经济过热"完全正确，加仓周期股仍亏数年（ZP-14证据）；基本面判断正确（2013影视手游无参与价值）但股票两年涨十几倍，看对没赚到（ZP-17证据）；2012年9—11月精准踩点、12月却狂妄看空错过牛市起点（ZP-29反面教训）；2015年9月反复止损至亏近4%、70%反弹只赚10%。
7. **框架逆风期代价**：2020年3月起看空未加回、远跑输市场，"正是坚守使其度过茅宁陨落"——坚守与跑输是同一枚硬币（ZP-33证据）；2014年历史级买点买入茅台格力平安，半年后因"价值陷阱"歧视压力悉数卖出、首秀失败；2018年底创业板胜率赔率俱佳却因信心被侵蚀涨50%即了结（ZP-24反面教训）。"统一场论"不可行——融合各路高手所长的体系耗费近5年失败（ZP-33反面教训）。
8. **结构性边界**：快速崩塌型股灾不适用"三年出清"时标（ZP-23边界）；纯题材庄股、个股不适用"跌70%出清"（ZP-20边界）；散户主导或外资/私募主导阶段抱团机制需修正（ZP-06边界）；极端央行行为（无限QE）不适用流动性加速器判断（ZP-15边界）；渗透率过低、商业模式不稳阶段时代贝塔过滤失效（ZP-11边界）；无历史对标的结构性新事物，案例匹配法失效（29章边界）。
9. **作者自注待验样本**：2022年底低估值风格引领下一轮的推断"只有留待时间检验"（ZP-01边界）；茅第三波/宁第二波为写作时点（2023.5初稿）推断而非已验证结论（26章边界）。
10. **心态层的系统性风险**："2012年那批中国版漂亮50多数后来被证伪（含乐视网）"——框架定位对了时代方向，个股仍需独立甄别（16章失败案例6）。

## 七、与大V体系的接口
