# S3 任务书 · 规律条目化（A1 聚类 / A2 门禁共享规范）

> 书籍蒸馏阶段3。本文件是所有 S3 子代理的统一规范，先读完再干活。

## 一、输入格式说明

三书 S2 语义单元有两种形态：
- **提取稿**（混合章）：`## M01 · 标题` 卡片，含论据/原文锚点/边界/类型（规律总结/机理分析/失败教训）
- **拆解稿**（A级章）：`### 论点N` + `## 三、可复用判断`（J01…，含依据/边界）+ `## 四、失败案例与策略失效教训`

## 二、A1 任务（半书聚类，不做门禁终判）

把本半的语义单元**按规律聚类**（同一条规律的多个卡片/论点合并成一条候选），产出：

```
## 候选规律
### C01 · <规律陈述，一句话，可独立成立>
- 覆盖单元：<文件短名>::M03、M05；<文件短名>::论点2
- 场景1：<章/年代>——<一句证据>｜锚点："<原文锚点逐字>"
- 场景2：…
- 预测力初判：能推导什么书外问题；或"仅解释历史"
- 常识度初判：非常识点在哪；或"接近常识"

## 现象候选（单场景/纯描述/纯解释，预判不够格入规律库）
- P01 · <陈述>｜<场景>｜<不够格原因>
```

规则：
- 场景引用**必须带锚点**（S2 卡片里的"原文锚点"字段原样搬运，不要改写）
- 本半只有 1 个场景支撑的规律**照样列入候选**，注明"半内单场景"——跨半补场景由 A2 负责
- 聚类标准：机制相同才算同一条规律；仅结论相似但机制不同（如"估值回落导致下跌"vs"业绩恶化导致下跌"）分开列
- 不要漏掉拆解稿的 J 系列可复用判断和"失败案例"节——失败教训常是独立规律候选
- 现象候选也要收集完整（降级去"现象记录"层的原料），宁多勿漏

## 三、A2 任务（单书门禁，glm5.3 判断核心）

合并本书两半候选 → 同书去重 → **逐条过三重验证门禁**：

1. **跨场景复现**：本书内 ≥2 个**独立**场景/时代支撑（A1 半内单场景的，去另半候选里找；找不到=不过）
   - "独立"标准：不同年代/不同市场/不同资产，不能是同一段行情换个说法
2. **有预测力**：能推出书外新问题的可操作判断（"如果X则大概率Y"），仅事后解释历史=不过
3. **非常识**：超出"一般老股民都知道"的水平；常识=不过（如"估值太高会跌"是常识，"新王崛起时旧资产便宜不是买入理由，会跌到意想不到的低估"是非常识）

三验全过 → 入规律库；任一不过 → 降级入现象记录（注明卡在哪一验）。

## 四、条目 schema（A2 输出，字段一个不能少）

```
### [ZP-01] <规律陈述一句话>
- 证据：场景1（章/年代+一句证据）；场景2（…）；≥2个独立场景
- 出处：《书名》第X章"章名"（原书页NN）；锚点："<逐字>"
- 数据截止：ZP=2022 / MG=2018 / QS=2021（书级统一，写书名对应值）
- 适用边界：<市场/制度环境/资产类型/失效条件>
- 冲突或印证：<书内已知的与其他来源观点关系；暂无写"待阶段B交叉">
- 反面教训：<书中对应的失败案例/策略失效；无则"无">
- 使用后印证：未使用（Query回写字段，保持原样）
- 三验记录：①跨场景：过（两场景：…/…）②预测力：过（可推导…）③非常识：过（…）
```

ID 前缀：周期估值与人性=ZP，美股70年=MG，全球股市启示录=QS。

## 五、纪律

- 锚点必须逐字搬运 S2 稿的"原文锚点"字段，**禁止自己改写**（阶段B有脚本回查）
- 数字引用与 S2 稿一致，不引入 S2 之外的记忆
- 研报/书籍自述结论照录，不加"我认为"
- 通过率预期 25-50%——门槛要真把关，防"正确的废话"灌水，但也不要为淘汰而淘汰
- A2 需在文件头部写执行统计：候选N条→入库M条→现象降级K条，各验卡关分布
