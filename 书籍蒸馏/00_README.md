# 书籍蒸馏（第四类项目 · 书版骨架）

> 建立时间：2026-08-16
> 定位：投资类书籍的体系化蒸馏项目。与大V蒸馏（碎片化发言）相对，书是**体系化、章节化**的原始材料，输入侧流程不同，但产物殊途同归——框架文档 → （视价值）skill/专家包。
> 流程唯一权威：`../00_蒸馏方法论/书籍蒸馏流程.md`（本目录不另立标准）

## 目录结构（书版骨架）

| 目录 | 用途 |
|---|---|
| `01_原文藏书/` | 书的 PDF/EPUB 原文，按 `书名/` 分子目录 |
| `02_章节拆解/` | 逐章/逐主题拆解笔记（书的核心资产，替代大V的"按年归档"） |
| `03_观点条目库/` | 结构化条目，内分两个子层：**规律条目**（方法论判断）+ **史实条目**（行情事件库），均带出处页码 |
| `04_框架提炼/` | **最终产物**：每本书的框架文档 + 跨书主题对照矩阵（先框架文档，确认价值后再视情况转 skill） |
| `05_工具脚本/` | 拆解辅助脚本（OCR、目录抽取、数字回查等） |
| `06_检索页/` | 检索入口（主题索引/市场×年代索引/条目全文检索，对齐大V蒸馏检索页模式） |

> 每本书在 01~04 下统一按 `书名/` 建子目录，不建书级独立 README，统一读本文件 + 主库流程。

## 运行约定

1. 选书 → 读 `../00_蒸馏方法论/书籍蒸馏流程.md`（**v2 正式版**：七阶段流程+模型分工+执行手册）
2. 原文入库（01）→ 章节分级 → 逐章精读（02）→ 条目化（03，规律/史实两子层）→ 框架提炼+跨书整合（04）→ 检索层（06）
3. 蒸馏质量标准、L1/L2/L3 边界规范**复用主库**，不重写
4. 框架文档定稿后评估是否提炼 skill（固化前按"三问"评估：适不适合固化 / 普适性 / 是否造成 skill 臃肿）
