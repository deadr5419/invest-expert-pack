## 1. 设计思路：为什么不能照搬大V蒸馏流程

大V蒸馏的产物是"**人物代理**"（他会怎么看 X）；这三本书的知识形态是三层，产物形态各不相同：

| 知识层 | 内容 | 价值形态 | 产物 |
|---|---|---|---|
| 史实层 | 美股 1948–2018 逐年复盘、全球各市场股市史 | **可查资产**，价值在查询与引用 | 行情事件库（市场×年代×事件） |
| 规律层 | 估值中枢、牛熊驱动因子、风格轮动、泡沫机制 | **可复用判断**，价值在带边界引用 | 规律条目库（统一 schema） |
| 框架层 | 凌鹏"周期-估值-人性"三变量框架、燕翔历史复盘方法论 | **方法论**，价值在接入投委会体系 | 框架文档 |

原五步法（选书→拆解→条目化→提炼→固化）缺四样东西：技术预处理分叉（扫描版 OCR）、三层知识形态的分别处理、跨书整合（燕翔两本同系列；凌鹏 A股视角 vs 燕翔全球视角的对照是最大增量）、与报告流程的调用接口（引用制）。

## 2. 产物架构（四层）

```
S0 洁净原文层   结构化全文：按章切分、章-页锚点映射、图表题注清单（机器可读）
S1 史实资产层   行情事件库：时间/事件/估值位置/驱动因子/后续演化，按 市场×年代 组织
S2 规律条目层   结构化条目：陈述/证据/出处(书+章+页)/数据截止/适用边界/冲突或印证
S3 框架与接口层  作者框架文档 + 跨书主题对照矩阵 + 检索页 + 条目引用制
```

## 3. 七阶段流程与模型分工

### 阶段0 · 原文规范化 ——【脚本为主，无需模型】

- 书目登记：元数据含**数据截止年份**（美股70年=2018、周期估值与人性=2022、全球启示录=待定）
- 文本抽取：
  - 《周期、估值与人性》：PyMuPDF 按 29 条书签切章，直接产出结构化全文
  - 《美股70年》：OCR 管线，三选一（按优先级）：
    1. **TextIn xparse connector**（智能文档解析，对中文扫描书效果好）——需先在连接器管理中连接授权
    2. 找**文本版电子源**（EPUB/mobi）替代扫描版——若能搞到则整条 OCR 成本归零
    3. 兜底：本地 PaddleOCR（注意大模型包下载的网络风险，需开代理）
- 清洗切块：去水印/页眉页脚、生成"章→页码区间"锚点映射、图表题注清单
- **验收**：全文可检索、每章带页码区间、乱码抽检 <0.1%

### 阶段1 · 章节分级筛选 ——【flash 初筛 + glm5.3 复核】

- 脚本先产出客观统计卡：每章字数 / 图表密度 / 数字与年份出现频率 / 结论句密度
- flash 逐章打标：**A级=方法论密集 / B级=史实数据密集 / C级=叙事过渡**，附一句话概要——只做分类打标，不做内容判断（对齐"flash 找对不做内容判断"原则）
- glm5.3 抽检 10% 复核 + 争议章定夺 → 产出**精读作战地图**
- 意义：此闸门直接决定 glm5.3 精读量（预计 A 级占 30–40%），是成本控制的总开关
- **验收**：全部章节定级、争议清零；作战地图标注每章处理方式（深读/转录/跳过）

### 阶段2 · 逐章精读蒸馏 ——【glm5.3 主力，内容层不拆】

- **A级章**：glm5.3 完整拆解——主旨 / 核心论点 / 论据 / 可复用判断 / 适用边界，全部带页码锚点
- **B级章**（两个模式，**待拍板**）：
  - 严格模式：与 A 级同，全程 glm5.3
  - **经济模式（推荐）**：flash 机械转录为史实表（时间/事件/数据）→ **脚本数字回查**（原文页字符串硬匹配）→ glm5.3 抽检 20% + 裁决存疑条目
  - 设计理由：史实转录是事实搬运而非内容创作；数字正确性靠脚本硬校验比任何模型更可靠，不构成"底稿-润色接力"（那条铁律防的是语义责任链断裂，硬校验不产生语义）
- C级章：跳过，仅登记
- **验收**：A级每章有拆解稿；B级条目数字回查通过率 ≥99%，未过的进人工待核清单

### 阶段3 · 规律条目化 ——【glm5.3 提炼 + flash 外壳】

- glm5.3 从 A 级拆解稿提炼规律条目，统一 schema：

```
条目ID | 陈述 | 证据（书中案例/数据）| 出处（书+章+页）| 数据截止 | 适用边界 | 冲突或印证
```

- 纪律：
  - **数据截止强制标注**——《美股70年》条目全部标"数据截止2018"，引用前须更新（对齐 [STALE] 纪律）
  - **与现有体系交叉引用**——如凌鹏周期框架 × 鹿鼎公煤炭周期观点，一致进"印证"、相反进"冲突"，登入条目字段
- flash 负责：JSON 格式校验、重复条目检测、入库
- **验收**：schema 100% 合规；出处抽查 100% 可回查到页

### 阶段4 · 框架蒸馏 + 跨书整合 ——【glm5.3，本项目最高价值层】

- 每书一份框架文档：
  - 凌鹏：周期-估值-人性三变量框架（周期定位方法、估值区间用法、人性/风格信号）
  - 燕翔：历史复盘方法论 + 长期规律世界观（两本一套）
- **跨书主题对照矩阵**（本项目最大增量）：主题（估值中枢 / 牛熊驱动 / 风格轮动 / 利率影响 / 泡沫机制 / 行业兴衰）× 三本书 → 互证处（一致结论，可信度上调）与分歧处（裁决记录，注明理由）
- **调用接口定义**（对接现有研究流程）：
  - 行业分析做历史类比时 → 查 S1 史实层
  - 估值纪律查长期估值中枢时 → 查 S2 规律层
  - 投委会大V发言需历史印证时 → 查主题对照矩阵
- **验收**：主题矩阵覆盖三书全部 A 级内容；分歧处均有裁决及理由

### 阶段5 · 检索层与 QA ——【脚本 + flash + glm5.3 抽检】

- 检索页 `06_检索页/index.html`（复用鹿鼎公蒸馏检索页模式）：主题索引 / 市场×年代索引 / 条目全文检索
- **引用制**：条目 ID 规范 `BK-<书代码>-<R规律|E事件>-<序号>`（如 BK-US70-R042 = 美股70年·规律42），报告引用格式统一
- QA 三层：脚本（锚点回查 / 乱码 / schema / 死链）→ flash（格式完整性）→ glm5.3（内容抽检：每书抽 10 条回查原文）
- **验收**：QA 报告全绿，或带 [待核] 清单显式交付

### 阶段6 · 价值评估与固化 ——【主会话 glm5.3 + 用户拍板】

- 框架文档定稿后过**固化三问**（适不适合固化 / 普适性 / 是否臃肿）：
  - 凌鹏框架 = 方法论，**固化候选**（可评估转 skill 或并入现有框架库）
  - 燕翔两本 = 证据资产，**建议保持知识库形态不转 skill**——它们是弹药库，不是决策代理
- 结论呈用户拍板，禁止默默固化

## 4. 模型分工总表

| 阶段 | dsv4-flash | glm5.3 | 脚本 |
|---|---|---|---|
| S0 原文规范化 | （可选）清洗抽检 | — | **主力**（抽取/OCR调度/切块/锚点） |
| S1 章节分级 | **主力**（逐章打标初筛） | 复核定稿（抽检10%） | 客观统计卡 |
| S2 精读·A级 | — | **主力**（完整拆解） | — |
| S2 精读·B级 | 初转录（经济模式） | 校验裁决+抽检20% | **数字回查硬校验** |
| S3 规律条目化 | 入库/格式校验/查重 | **主力**（提炼+边界判断） | schema 校验 |
| S4 框架+跨书整合 | — | **主力**（独占） | — |
| S5 检索层+QA | 格式 QA | 内容抽检 | **主力**（检索页/锚点/乱码） |
| S6 固化评估 | — | 主会话 | — |

**分工一句话原则：flash 管"搬运与打标"（不改变语义的结构化工序），glm5.3 管"理解与判断"（凡产出会进入报告引用链的语义工序），数字正确性优先交脚本硬校验而非任何模型。**

## 5. 执行顺序（样板工程策略）

1. **立即**：《周期、估值与人性》全管线跑通——文本版无技术障碍，作为**样板工程**验证 schema、QA 标准、产物形态
2. **并行**：解决《美股70年》OCR 前置条件（TextIn connector 授权，或找文本版电子源）
3. **到货**：《全球股市启示录》鉴定版本后入对应管线
4. **收口**：燕翔两本同系列，阶段 4 的跨书主题矩阵与阶段 5 检索层在三书齐备后一次性建成

## 7. 风险与对策

| 风险 | 对策 |
|---|---|
| OCR 数字错录（图表密集书最易错） | 图表数据条目一律标 [OCR待核] + 脚本回查 + 人工待核清单；优先文本版源 |
| 知识陈旧（美股70年数据止于2018） | 数据截止强制标注 + 引用时提示更新（对齐 [STALE] 纪律） |
| 全球股市启示录版本未知 | 预留文本版/扫描版双管线，到货即鉴定 |
