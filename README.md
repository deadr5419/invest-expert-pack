# 投研专家团 · 开源包

WorkBuddy 投资研究专家团（Team 型投委会）+ 书籍蒸馏知识库，随包分发。

## 部署方式（给 AI 的执行指令）

> **把本仓库交给 AI 即可完成部署**：请 AI 读取并执行根目录下的 `AI_DEPLOY.md`
> （AI 部署指令书，含可执行步骤、路径回写、验收清单）。
> AI 会自动完成：安装专家市场 → 放置书籍知识库并回写路径 → 部署验收 → 数据源引导。
> 人类需要做的只有两件事：**重启 WorkBuddy**、**按引导配置自己的数据源账号**。

## 安装（人工方式，AI 部署失败时的手动备选）

1. **安装专家市场**（二选一，推荐 zip 导入）：
   - ✅ zip 导入：把 `expert-market/` 压缩成 zip → 设置 → 插件市场 → 导入 zip（**无需手动放路径**，软件自动管理）
   - 手动放目录：解压到 `~/.workbuddy/plugins/marketplaces/expert-market/`（Windows 为 `C:\Users\<你的用户名>\.workbuddy\plugins\marketplaces\expert-market\`），重启 WorkBuddy 后在左侧「专家」中导入市场
2. **放置书籍知识库**：`书籍蒸馏/` 目录**放哪都行**（建议放研究目录如 `C:\Users\<你的用户名>\Desktop\市场研究\大V研究\书籍蒸馏\`），保持内部结构完整即可。专家包内 comps-valuation 与 industry-analysis-method 技能会引导到该检索页，AI 会自动定位实际路径
3. **配置数据源**（专家包不捆绑任何账号）：
   - 腾讯自选股：WorkBuddy 连接器市场安装「腾讯自选股」连接器（实时行情，免费）
   - Tushare：注册 tushare.pro 获取 token，配置到 Tushare skill（历史批量数据）
   - Wind：配置 Wind 金融数据连接器（跨市场权威核验，每日免费积分）
   - 研报平台：如需研报采集能力，自行配置 fxbaogao 类工具与额度

## 使用纪律（随包约定）

- **大V观点 ≠ 事实**：鹿鼎公/山行/回收再利用的输出一律标注"XX观点"，供思路与框架参考，不代结论
- **数据自核**：关键数据自行核实，无法核实标 `[待核]`
- **引用带 ID**：引用书籍规律须带条目 ID（如 MG-01、QS-31），现象条目（未过三验）只作线索不作依据
- **注意数据时点**：书籍规律数据截止 2018/2021/2022，引用时标注时点差
