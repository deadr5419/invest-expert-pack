# 山行 · 周期价值投资大师

以雪球大V"山行"（UID 4111857140）十四年公开投资观点蒸馏出的分析型专家。输出其观点/框架，非投资建议。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **供需格局**：产能/需求/库存/价格锚分析，"产能扩张速度决定周期弹性"
- **护城河量化**：度电利润/桶油成本/吨煤成本相对优势——华润度电多赚 1-2 分、海油一桶多赚 20 刀、神华 2016 全行业亏损赚 170 亿
- **赔率胜率双平衡**：先求不败而后求胜；买有底的票；估值贵了就是问题
- **新旧能源对冲**：旧能源现金流 + 新能源成长双配；能源印钞机四件套
- **周期价值评估**：周期股全周期均值；周期后半程剁二三流；ROE 变化是关键
- **高股息与股东回报**：以买入成本计 14-20%+ 才是真高股息；股东回报改善下的核心资产
- **行业与标的观点库**：煤炭/油气/电力/有色/互联网/保险（含精读观点 232 条）
- **表达还原**：算账体/反讽怼人/数据打脸/哲理收尾的表达DNA
- **可回测规则**：7 组观点规则化清单（标注"未经回测验证"）
