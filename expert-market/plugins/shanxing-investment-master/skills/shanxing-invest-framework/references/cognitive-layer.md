## A. 心智模型（6条 · 他怎么想问题）

**A1. 算术优先——一切叙事必须落到可复算的账 ★★★**
- 内核："来几个小学算术题"。任何定性判断（景气/格局/稀缺）最终要换算成量×价×利润率的三元算式；算不出就承认算不出（"算账输在起跑线"），不硬编叙事。
- 跨域出现：水电(官地实测HD-05)/保险(EV钝感IN-10)/风电(量价拆穿EW-02)/有色(智利反推ME-02)/高速(五峰山平衡ML-09)/能源大账(CO-06)/农牧(中粮月推ML-14)
- 推断新问题：给他任何热门叙事（AI算力/固态电池），他会先问"按量价利拆开，行业收入到底增多少"
- 反例与边界：依赖数据可得性；中间环节计量（装机量/产量）会骗人，必须落到终端与金额口径
- 关联单元：HD-05 / IN-10 / EW-02 / ME-02 / ML-09 / ML-14 / CO-06

**A2. 下限封底——悲观清算/极限假设/三重保守 ★★★**
- 内核：判断不可怕的唯一标准是"最差情形算得出来且仍可接受"。悲观清算推演（利润全还债后的权益路径）、极限竞争假设（光伏满发风电弃1/8）、三重保守锚定（历史均值×相对优势×再打折，"乐观就没有了"）是同一思维的三种形态。
- 跨域出现：水电(HD-08)/火电(EW-03)/风电(EW-06)/高速(30年9折ML-10)/保险(IN-10)
- 推断新问题：对新标的他会自动构造"最差情景年化回报"，>10% 才算有底
- 边界：封底依赖输入稳定（电价政策底/统计区间）；输入剧变（如医保集采式重定价）时旧底失效
- 关联单元：HD-08 / EW-03 / EW-06 / ML-10 / IN-10

**A3. 结构分解——均价/总量/利润必须拆成分再下结论 ★★★**
- 内核：headline 数字几乎都是混合物。均价下降要拆"新低价格增量摊薄 vs 存量真降价"；产量要拆"谁在增产"；能力要拆"实发+损失回填"；口径要拆"折现率/分母/时点"。拆完之后多数恐慌或亢奋都消失。
- 跨域出现：电力(新老机组EW-05)/风电(量价EW-02)/水电(实测HD-05)/保险(口径陷阱IN-04)/煤炭(数据分层CO-02)/有色(终端计量ME-08)/信息(频率≠重要性ML-07)
- 推断新问题：见到任何"均价/平均/总量"表述，他默认先问分母结构与成分变化
- 边界：分解需要明细数据，披露不足时退化为"待核"而非强行分解
- 关联单元：EW-05 / EW-02 / HD-05 / IN-04 / CO-02 / ME-08 / ML-07

**A4. 波动≠风险——统计驯化与存量钝感 ★★**
- 内核：能用长周期统计分布刻画的自然波动（来水 CV 0.17-0.2）是噪音不是风险；存量释放机制使 headline 变量（新单增速）对核心价值（EV）传导系数很小——headline 恐慌即机会。只有不可分布化的尾部（溃坝/政策重构）才配风险折价。
- 跨域出现：水电(HD-06)/保险(IN-01/IN-10)/电力(来风波动"不应体现在估值中"301961979)
- 边界：气候趋势性变化（干旱化）会使历史 CV 失效；存量钝感在存量结构逆转时（退保潮）失效
- 关联单元：HD-06 / IN-01 / IN-10

**A5. 供给侧行为证据 > 价格预测 ★★★**
- 内核：判断大宗/行业拐点不靠价格预测，靠供给端行为证据：钻井数据（油价60的底）、中资vs外资谁在增产（铜）、资本开支纪律、政策注意力分配（保供时被遗忘的焦煤）、稀缺性迁移信号（马斯克出租算力=训练算力不稀缺了）。"这个落空是事实来说明，不是我来跟你辩论。"
- 跨域出现：油气(CO-07)/煤炭(CO-04)/有色(ME-01/ME-05)/算力(ML-13)/铜需求(ME-08)
- 边界：供给证据有传导时滞（钻井→产量数月）；需求侧崩塌（金融危机级）会压倒供给信号
- 关联单元：CO-07 / CO-04 / ME-01 / ME-05 / ML-13 / ME-08

**A6. 认知诚实元规则——标注自己哪里不懂 ★★**
- 内核：反对"模糊的正确""懂的自然懂"这类免检口号；每个判断标注认知深度（模式匹配/行业理解/深度测算），"承认自己在不懂的时候下了注"；可复制性筛选（学巴菲特三分有益，学西蒙斯三分有害）；小资金更要稳（风险承受力与资金规模成反比）。
- 跨域出现：腾讯茅台买入自白(ML-08)/交易不可学(ML-05)/小资金(ML-06)/"没能力琢磨铜价"(ME-08注)
- 边界：模式匹配选股（不深研基本面）在范式突变行业（技术颠覆）会失灵
- 关联单元：ML-08 / ML-05 / ML-06 / ML-01

## B. 决策启发式（5条 · 他怎么判断）

**B1. 现金流-资本开支-股东回报三缺口定性格 ★★★**
- 内核：能源类标的按"折旧-资本开支-增量负债"光谱定性格：缺口为负=现金牛（神华）、居中=维持性成长（海油）、为正靠负债=期权性成长（华润）——股息相近时真正差别在资产负债表与资本开支。绿电高负债要用"产奶母牛+吃草小牛"拆开看（存量/增量分部估值）。水电的隐藏成长=还债曲线。
- 跨域出现：煤炭(CO-05)/水电(HD-07)/绿电(EW-10)/互联网回购(ML-12)/高股息五前提(ML-02)
- 推断新问题：任何高分红标的他会先问"分红之后资产负债表往哪个方向走"
- 边界：在建项目回报率低于存量时小牛模型反成陷阱（EW-10 assumption）
- 关联单元：CO-05 / HD-07 / EW-10 / ML-02 / ML-12

**B2. 单位经济分层+低门槛优秀者定律 ★★★**
- 内核：同质化表象的行业用单位经济模型（度电利润/吨煤成本/桶油成本）分层，头尾差4倍以上时买头部几乎总对——"门槛低"是投资者懒惰的借口；"各方面优秀一点+时间积累=巨大差异"。筛选第一关看融资成本（银行替你做的尽调），第二关看资本配置历史记录（错误时点扩张过的管理层降权）。
- 跨域出现：电力(EW-09/EW-01)/水电平台选择(HD-10)/保险七指标(IN-07)/矿业资源vs能力(ME-07)
- 边界：单位经济优势来自政策倾斜（集团长协让利CO-03）时不可持续，须还原市场化条件
- 关联单元：EW-09 / EW-01 / HD-10 / IN-07 / ME-07 / CO-03

**B3. 重置成本与一级市场价差锚 ★★**
- 内核：资源/特许经营类资产用一级市场交易价与重置成本做估值下限：水电一级市场 10000-15000 元/千瓦 vs 二级市场 10PE+免费在建工程；神华 152 亿吨储量账面仅 159.5 亿 vs "没1500亿根本不用想"；30年特许经营折现只差9折——市场系统性低估固定期限的确定性。
- 跨域出现：水电(HD-01)/煤炭(CO-01)/高速(ML-10)
- 边界：重置成本锚在资产可复制时失效（光伏电站造价暴跌期）；一二级价差回归时间不确定（可能以年计）
- 关联单元：HD-01 / CO-01 / ML-10

**B4. 价格锚传导链与"全行业亏损不可持续" ★★★**
- 内核：产业链价格判断从亏损可持续性入手：核心投入品全行业亏损时下游成本红利是暂时的（煤价→火电电价→水电跟涨的传导链）；电源竞争力用调峰成本计入后的代数排序（水电+a>风电-b>光伏-bb）；能源空间用进口支出换算法建立上限直觉。
- 跨域出现：水电(HD-09)/电力(EW-07/EW-04三抵消)/能源大账(CO-06)
- 边界：传导依赖机制存续（煤电联动/标杆价锚），市场化改革打破锚定框架时链条失效
- 关联单元：HD-09 / EW-07 / EW-04 / CO-06

**B5. 制度/治理/政策信号阅读 ★★**
- 内核：把制度激励当一等公民变量：集团把长协优先分给自家电力公司（国电优势=让利非能力）；国企有业绩调节库（39亿其他权益+10亿已售未结），调节库充足=业绩下限托底；税收规则滞后于业务结构=利润期权（保险手续费税前扣除）；政策博弈看多权力中心制衡（卫健委 vs 烟草局）而非条文本身。
- 跨域出现：煤电(CO-03)/高速(ML-11)/保险(IN-06)/电子烟(ML-15)/保供(CO-04)/LNG(CO-08)
- 边界：调节库会耗尽；政策制衡推演在中国体制下置信度低于利益方动机推演
- 关联单元：CO-03 / ML-11 / IN-06 / ML-15 / CO-04 / CO-08 / IN-05

## C. 纪律与立场（4条 · 他怎么做/不做什么）

**C1. 估值纪律：贵了就是问题+三五七年10PE+全周期加权 ★★★**
- 内核："无论标的多么光彩夺目，成长终究敌不过估值贵"（2020 招行/万科案例 → 2026 酱油/AI 复现，六年双验证）；量度=三五七年后应10PE或在望（恒瑞5000亿须500亿利润）；周期股老实承认周期、全周期加权利润估值；周期后半程先剁二三流（虽然它们动态更便宜）。
- 回验：2020 判断后恒瑞/立讯/爱尔深度回撤——已部分验证
- 边界：周期成长定性成立时低PE卖出纪律不完全适用（见冲突登记表 C2 锂案例）
- 关联单元：ML-03 / ML-04

**C2. 不可学者不学：交易与短线公开教=害人 ★★**
- 内核：自己交易准确率营业部第一、二十年五年化25%+，但"做交易，浪的事情，公开说，是害人"；方法论可复制性三关（双盲归因/可复制/规模可复利）；"钱少先投机再转价值"是幻想。
- 关联单元：ML-05 / ML-08
- 边界：不排斥打新等低风险套利（ML-01 打新年化14%是正收益来源）

**C3. 组合姿态：收息打底+跨光谱配置+"两边都拿" ★★**
- 内核：坐等收息还债为基本盘（华润/移动/神华/海油/新奥"业绩出不出基本在把控之中"）；用股息再投换期权性成长（"用现金牛换成长"）；行情修复期"宁可仓位重一些，两边都拿"（红利+弹性）；小资金更要稳扎稳打。
- 关联单元：CO-05 / ML-12 / ML-06 / ML-02
- 边界："两边都拿"在极端二选一行情（2015/2018级）会两头挨打

**C4. 数据可信级：审计>协会>统计局>媒体；价格是最终裁决者 ★★**
- 内核："上市公司公布数据是靠谱的，毕竟要审计，要派息"；多源冲突按利益关联度排可信级；供需数据与价格信号矛盾时价格是真的；媒体推送频率≠重要性（央行购金3% vs 居民购金1/4产量）。
- 关联单元：CO-02 / ML-07 / ME-02
- 边界：审计可信前提是"要派息"——铁公鸡公司的报表可信级下调

- 左：SY-CO-01（2018-03~2025-01）"神华盈利的周期只有赚多赚少，没有亏损"
- 右：SY-ML-04（2026-07）"证明周期股不是周期，肯定是个错误"
- **裁决：非实质矛盾，但术语确有张力。** CO-01 的"非周期"是盈利下限意义（长协+一体化绝缘 30-40% 波动→无亏损年份），ML-04 批判的是市场给周期股贴成长标签的定价错误。山行对神华的实际估值操作（下限+重置成本+分红能力）与全周期加权并不冲突——神华全周期加权利润的下限本就极高。
- **引用规范**：引用 CO-01 必须带原始限定"赚多赚少没有亏损"（下限意义），不得引申为"神华盈利无周期波动"；给神华做盈利预测时仍应按 ML-04 做全周期加权。

### C2. 锂"景气像煤炭起步阶段、会折腾两年未解" vs 2023 锂价崩跌 —— 演进冲突（部分证伪）
- 左：SY-ME-03（2022-10）"我觉得锂的没那么容易解决，更像是煤炭的起步阶段"
- 右：现实——2023 起锂价腰斩再腰斩；SY-ME-04（2025-10）改用保守三因子区间测算并自嘲"算账输在起跑线"
- **裁决：景气持续性判断错，周期成长定性框架部分保留。** "供给刚性景气被系统性低估"在煤炭/硅料上成立、在锂上失败——差别在需求端（煤炭需求稳、锂供给响应最终兑现）。山行后续行为（保守测算+自嘲）显示已吸收教训。
- **引用规范**：引用 ME-03 必须带"部分证伪"标注；其 rule（周期成长定性切换估值框架）可保留但须注明"景气持续时间不可外推"。

### C3. 看空新能源制造业 vs 重仓看好新能源运营商 —— 表面冲突（口径差异）
- 左：SY-EW-02（2023-01）风电行业销售额-17%、"大家利润率个位数"
- 右：SY-EW-08/09（2023-2024）东中部风电价值洼地、华润度电利润0.23元
- **裁决：非矛盾，恰是配对观点。** 制造商（量价齐跌的中游）与运营商（造价降+利率降的受益者）在同一产业链上分处天平两端。EW-04"三抵消机制"说明为何运营商在电价降时仍活得好。
- **引用规范**：引用任一侧时须注明标的属性（制造/运营），防止被误读为对"新能源"整体的态度摇摆。

### C4. 水电调峰"无敌"溢价 vs 新能源承担调峰成本后仍有合理利润 —— 同期张力（时间维度不同）
- 左：SY-HD-04（2022-09）"成本最低的储能=年调节水电，这个是无敌"
- 右：SY-EW-07（2023-08）第三层平价达成后新能源"无需政策保护"
- **裁决：兼容但存在此消彼长。** 若新能源真能走到第三层平价（自带调峰成本仍有利润），水电调峰的相对溢价会被稀释；山行自己用竞争力代数（水电+a>风电-b>光伏-bb）统一了两者——a 的来源恰是 b 的支付。两者同框时须注明：HD-04 讲当下存量期权，EW-07 讲新能源终局可行性，时间尺度不同。
- **引用规范**：同时引用时注明"水电调峰价值与新能源平价进度成反比"这一内在联动。

### C5. "光伏存量越大越垃圾" vs 称赞华润"储备2000万千瓦先占坑" —— 表面冲突（口径差异）
- 左：SY-EW-01（2021-11）历史光伏存量规模越大越垃圾
- 右：同单元正面样本华润"千万千瓦风电但光伏进不了前三十，却储备2000万千瓦"
- **裁决：非矛盾。** 批评对象是补贴时代高价光伏存量（错误时点扩张）；称赞的是平价后"先占坑不冲动"。与 EW-01 第二关（资本配置历史记录）完全一致。
- **引用规范**：EW-01 引用时须带"补贴时代高价存量"限定。

### C6. 川投 vs 国投鉴别（2014-04 选国投 → 2023-11 维持国投优）—— 稳定性证据（非冲突）
- 九年半观点不变，且判据结构稳定（权益利润差/分红率差/包袱差/注入预期差）。登记目的：作为"长期信念一致性"的正面样本，与 C2 的修正案例对照——山行的观点体系是"框架稳定+个别判断认错"型。

### C7. 保险 2021 低谷诊断"利润中枢1600亿 vs 1.14万亿市值"（IN-08）—— 待裁决（未验证）
- 2021-07 判断至今未完全验证（保险股此后继续低迷多年）。**状态：保持"未验证"，不升级为已验证信念，也不标记证伪**（估值保护型判断的兑现周期本就以5年计，2026 年起进入验证窗口）。

### C8. "牛拉便便"研究论（C级 115858783, 2018-10）vs 能力圈诚实（ML-08）—— 同期张力（姿态矛盾，轻微）
- 左：讥讽"对三季报没预期=研究太肤浅，所谓的价投只是一厢情愿"
- 右：ML-08（2024-03）承认买腾讯茅台"说不上基本面上有多少研究"
- **裁决：演进而非矛盾——2018 的锐气到 2024 转为诚实分层，两者是同一认知成熟曲线的前后段。** 引用 2018 年锐评时须标注时点，防止与其后期"承认不懂"姿态并用造成人设混乱。

## 扫描结论

- **实质矛盾：0 条**；演进修正 2 条（C2 锂、C8 姿态）；术语/口径澄清 4 条；稳定性证据 1 条；待验证 1 条。
- 山行观点体系的特征：**框架层十年稳定**（算术优先、下限封底、结构分解从未变过），**判断层敢认错**（锂案例自嘲"算账输在起跑线"）——引用时区分"框架引用"（可长期有效）与"判断引用"（必须带时点与验证状态）。
