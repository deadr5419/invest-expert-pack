## A. 心智模型（5条 · 他怎么想问题）

**A1. 熊牛不加身——买贵是亏损唯一原因 ★★★**
- 内核：任何股票都有合理价格；买入视角永远按"冰河世纪永不抬升"假设，靠业绩+分红算账。催化剂/风口叙事=附带幻想=最容易买贵。
- 跨域出现：银行(2023-12)/电力(2024-11保守八条)/糖(2024-07利润底)/油运(2025-12)
- 推断新问题：对任何热门赛道股，他会先问"假设估值永不抬升年化多少"
- 反例与边界：极端系统性危机中"合理价格"锚本身失效；对纯成长无分红标的不适用（他直接排除这类）
- src: 272406674 / 311266890 / 296968068

**A2. 先求不败而后求胜——胜率赔率分层配置 ★★★**
- 内核：下有底（股息+资产稀缺性）的票打底（约7成），弹性仓另配；通过做T+收息降本。"跌到哪里去"优先于"涨到哪里去"。
- 跨域出现：国电(2025-03)/南油淮河(2025-12)/煤电铝三角(2025-04)
- 推断新问题：任何新标的他先给"底"的定义（股息率多少+什么资产托着）
- 边界：底依赖判断可靠；底判断错（如政策剧变）时纪律会变成接飞刀
- src: 327967012 / 367083090 / 331143536

**A3. 股价共识论——基本面与股价不同步 ★★**
- 内核：股价=共识。共识未形成前业绩再好也不涨（四大行前五年）；共识形成后基本面走下坡也新高（神华利润顶22Q2→股价顶24Q3）。持股期要判断"共识处于什么阶段"。
- src: 342926064 / 362752021
- 边界：共识判断本身主观；他对"共识多久形成"的预估可能过于乐观（"不会太久"）

**A4. 二阶模式——投股权现金流不投商品价格 ★★★**
- 内核：一阶行情跟现货涨跌；黄金时机=商品价格从情绪高点回落+价格中枢不可逆抬升+股价深度折价（二阶）。盯企业ROE/现金流，不盯商品报价。
- 跨域出现：电解铝(2026-06)/火电重估(2024-12)/黄金股关注(2026-06)/煤炭
- src: 396305849 / 317046462
- 边界："中枢不可逆抬升"判断错时二阶变一阶陷阱；对供给可快速扩张的商品不适用

**A5. 势先于标的 ★★**
- 内核：不要让战术上的勤奋（分析个别标的）替代对势的判断。研究漏斗=势→通用性天花板→产能弹性→个股。专用百亿/通用万亿；产能扩张困难+当下过剩=反转快。
- src: 391039413 / 354418778
- 边界：宏观势判断他自己承认"盲人摸象错误百出"，故退回"螺蛳壳里钻"个股深研

## B. 决策启发式（7条 · 他怎么判断）

**B1. 定海针三问估值法 ★★★**
- 内核：稳定分红股以长电（收息锚）/茅台（消费锚）为坐标：风险/分红率/增长率各较两锚何如？答完买贵很难。股息率区间=无风险利率+风险溢价，分红率直接决定估值上限。
- src: 283469326 / 292933129
- 推断新问题：给他任何收息股他会自动跑三问
- 边界：仅限稳定经营+稳定分红；周期股用B2

**B2. 利润底×股息保底×看涨期权三层结构 ★★★**
- 内核：周期混合体估值=反事实法算利润底（无周期红利时多少）→股息率保底→周期弹性当免费期权。
- 跨域出现：中糖(11-12亿底+4%股息+糖价期权)/国电(保底分红+水电成长)/南油(12亿底+3.4-3.8%股息+运价弹性)
- src: 296968068 / 367083090 / 347656225
- 边界：利润底测算依赖"剔除干扰项"的还原准确；底被证伪（如糖价破区间）需重算

**B3. 权益口径铁律——控股规模是给电网看的，权益才是给股东看的 ★★★**
- 内核：装机/电量/资产一律换算权益口径再比较；警惕双重稀释（北京国电57%×项目合资；远达→中国电力两层稀释后仅30%+）。
- 跨域出现：江浙皖权益装机/雅大对比/中国电力/神皖——≥4次
- src: 368407609 / 347058431 / 341267561 / 383876534
- 推断新问题：给他任何"装机大省/资产巨头"叙事，他会先画权益穿透图
- 边界：权益数据常需推测，精确度有限（他自注"权益比例为推测值"）

**B4. 年报外数据源体系——公司债募集书是第二年报 ★★★（标志性方法）**
- 内核：子公司发债募集书/绿色债/MTN披露年报没有的经营数据（电价/毛利率/费用全序列）；20年前的环评/水资源论证报告可当政策冲击预演证据；关联交易金额序列反推未披露结构。
- 跨域出现：国能江苏MTN002(电价证伪)/大渡河绿色债(财务对比)/大岗山环评(调水影响)/燃料关联交易(4年序列)——≥4次
- src: 369273424 / 371406976 / 336849666 / 321656024
- 推断新问题：遇到数据缺口他的第一反应是"这主体发过债吗"
- 边界：发债主体覆盖不全；发债间隔期数据滞后

**B5. 应收账款三表+计提激进度修正 ★★**
- 内核：净利润只是表象。比利润先比：应收净增幅/应收占营收比/周转率+账龄结构+计提政策。应提尽提者（国电）利润含金量高于零计提者（赌补贴不拖欠），市场定价常给反了。
- src: 348456418 / 364834267
- 边界：港股披露不细（他自己注明）；补贴最终兑付是不确定假设

**B6. 治理筛选——永续债/定增双零+回购注销=厚道 ★★**
- 内核：永续债两宗罪（虚降负债率+税后扣息吞EPS）；负债率高但双零的公司是"老实"。三还原：负债率还原/PB还原/EPS还原。
- src: 338369955 / 381542657 / 376992305
- 边界：主动还永续债的公司（华电"还的最积极"）可翻案

**B7. 国企利润调节器模型——利润总额>归母净利润 ★★**
- 内核：国企计提是利润平滑工具（"兄弟喝粥你不能大鱼大肉"）；利润总额（扣计提前）是考核口径更真实；用"利润总额完成率"新闻倒推全年目标。
- src: 347656225 / 321234177
- 边界：依赖国企考核机制的持续性；民企不适用

## C. 行业认知（8条 · 他对行业的结构性判断）

**C1. 火电终局=稀缺辅助电源+稳定收息资产，小时数底4000 ★★★**
- 内核：五步推演（不新建→机制理顺→转辅助→煤耗达峰→独特盈利模式）+36亿千瓦目标倒推4000小时底。火电"过剩却不多余"——能源安全决定产能不萎缩。
- src: 317046462 / 354418778 / 352578452
- 边界：容量电价政策是前提；风光成本若再大幅下探挤占超预期则底破

**C2. 容量电价封死爆亏通道 ★★**
- 内核：21-22华能纸面巨亏但现金流未亏（差额=折旧）；容量电价=覆盖固定成本的补贴→极端煤价下不再巨亏。
- src: 362752021
- 边界：以21-22煤价为压力上限；更极端情形未测试

**C3. 电不是同一种商品——均价变化先拆结构效应 ★★**
- 内核：公交/地铁/出租车类比；全国性公司均价由电量结构决定（燃机占比高→均价高）；"电价降3分"常是低价电占比上升的结构现象。
- src: 352578452 / 332778898 / 343482486
- 边界：现货市场成熟后分时价差显性化，结构拆解的可观测性提升

**C4. 长协=开盘价——加权电价算法反线性外推 ★★**
- 内核：长协只是"开盘集中撮合价"（60%），月竞20%+现货20%构成全年；"长协降X分=全年降X分"是线性错误。总量反算可构造悖论逼空头叙事自相矛盾。
- src: 369530565 / 373597983 / 384489441 / 368218912
- 边界：各省规则不同（比例/上下限），套用需查当地规则

**C5. 成长期水电的财务费用是"封印"不是缺陷 ★★**
- 内核：大渡河多发120-167亿度电利润才与桂冠持平，差在电价+财务费用；财务费用随偿还递减=利润释放通道；区位（离成渝最近）决定长期电价；资本开支高峰结束时点=价值拐点。
- src: 371406976 / 324746821 / 327417782 / 354209026
- 边界：利率环境变化影响释放速度；留川电价机制是变量

**C6. 糖商vs糖厂+油价糖醇比传导链 ★★**
- 内核：中糖是熨平周期的糖商不是纯多头；糖价底部在油价（油价→糖醇比→糖产量→糖价）；配额+沿海卡位+海外渠道+套保=炼糖四重优势；进口政策细分项=供需风向标。
- src: 285052350 / 288221769 / 289572200 / 301834508
- 边界：巴西能源政策剧变会断传导链

**C7. 电解铝护城河=中国电力系统+产能指标制度稀缺 ★★**
- 内核：电解铝享受中国电力低价/安全/稳定/低碳系统优势；国内产能红线=制度性护城河；海外巨量规划大多是骗资源；东南亚铝土矿视同本土资源；AI物理世界=铝合金世界。
- src: 396869783 / 392832322 / 304408678
- 边界：电力系统优势是宏观前提；产能指标政策若松动则逻辑动摇

**C8. 特高压配套支撑火电=印钞机 ★**
- 内核：送受端价差>输电成本（0.1-0.12元/度全链）+低成本煤+高小时数=暴利；评估三步：电量大数自洽→输电成本拆解→价差覆盖测试。
- src: 364700847 / 368108943（上海庙）
- 边界：送端电价机制各省不同

### F1. 对华润电力的判断：严厉质疑 → 有条件转多
| 时点 | 观点 | 语境 |
|---|---|---|
| 2025-08《高估低估你真的能看懂么》 | 应收五年净增90% vs 同行30-40%、占营收33.2%、周转率3.1 全面劣于同行；"远优于同行的利润真拿到了么？"质疑计提不充分、质疑华润新能拆分动机 | 横向数据对比框架下对盈利质量的质疑；其后股价走势他自评"印证了我的观点" |

**裁决**：演进冲突。两个维度并不矛盾——2025-08质疑的是**盈利质量（应收/计提）**，2025-12看多的是**电价冲击下的相对韧性**。引用时必须区分维度。风险提示：他自己在12月文里也说"PS：先自我保护一手"，说明对应收问题并未撤诉。
**回答规则**：问"他怎么看华润"必须分两段：质量层面（持续保留质疑）+ 价格冲击层面（误伤，2025-12时点）。

### F2. 对淮河能源的估值定位：中性 → 积极逢低加仓
