# 研究思路与方法论（鹿鼎公的分析范式提炼）

> 这是本 skill 的**方法论层**：把鹿鼎公对行业/企业的研究路径提炼成可复用的分析范式，供分析新标的时套用。全部为其公开分析中体现的方法，标注出处。

## M1 需求结构拆分法（自上而下看行业）
- 把行业需求拆成可量化的子项，逐个估算量级（例：煤炭需求六分法——火电>50%动力煤、钢铁焦煤6.5亿吨、水泥陶瓷7-8%、化工3-3.5亿吨、民用散煤1.5-2亿吨、其他散煤1.5-2亿吨；2024 原话）
- 用途：判断需求端弹性与不可替代性，避免"需求崩了"的恐慌
- 出处：2024 发言精选（上）

## M2 多空因素清单法（对价格/行业做双向盘点）
- 对当下价格走势，分别列出全部利空与利多，逐条给权重（例：2024 煤价大跌 100 元，他列了 3 条利空 + 6 条利多：云贵大旱、夏季空调耗电、油价80美元托底煤化工、发电煤双支撑、新疆汽运煤生命线、山西严抓超产）
- 用途：不做单边叙事，识别"持币待购瞬间变抢货潮"的转折点
- 出处：2024 发言精选（上）

## M3 盈利测算框架（周期股：价格→吨利→EPS→PE→分红）
- 链条：假设商品价格 → 吨净利 → 全年 EPS → 对应 PE/股息率 → 判断低估/高估
- 例（电解铝 2026-05）：铝价锚 23000 元 → 吨净利 6800 → 云铝/神火 EPS 约 3.3 → 除权后 PE 8.5 倍 → 前瞻分红约 5%
- 关键：**参数全部显式列出**（价格、成本、分红比例），可复算、可证伪
- 出处：微博 2026-05-15 原帖

## M4 同业对比法（同赛道标的横向拆解）
- 对比维度：权益产量（上市公司实际拥有 vs 集团）、资源类型（露天/深井）、效率、分红比例、未来增量项目
- 例（内蒙华电 vs 陕西能源）：都是煤电一体，但魏家峁 1500 万吨全是上市公司（内蒙华电）的、且是露天矿 → 煤炭利润反而高过权益更高的陕能；陕能潜在利好是赵家畔煤矿 2026 年贡献利润
- 结论常反直觉：**报表权益 ≠ 上市公司实际利润**，要穿透到权益口径
- 出处：2024 发言精选（下）

## M5 分红回本年限法（收息股的估值语言）
- 用"当前价需要 N 年分红才能回本/算便宜"来锚定买点
- 例（神华H）：40 元需 4-6 年分红才算比较便宜；30 元只需 1-2 年
- 用途：把估值翻译成收息投资者最敏感的"回本年限"，配合利率环境判断
- 出处：2024 发言精选（下）

## M6 估值锚定法（DDM 简化版）
- 规则：分红率 >40% 按实际计算，<40% 按每股盈利的 40% 计算；折现率取 10% 左右；"价值之锚都是极端情况下的预估"，买入时做好"到达价值之锚"的对策
- 买入价在绝对估值结果上打 7-8 折（安全边际）
- 出处：资料集笔记（价值之锚）、深度研究报告

## M7 个股速评框架（几句话评估一只票）
- 例（中远海控，2023）：①PB 历史最低、净现金≈市值、资产负债表优秀；②资本开支克制（每年 100 多亿）；③预计股息 10%+；④行业周期底部、上半年复苏中；⑤运营绩效高于同行；⑥账上 700 亿隐藏利润平滑周期
- 框架：估值（PB/净现金）→ 资本开支纪律 → 股息 → 周期位置 → 相对竞争力 → 隐藏资产
- 用途：评估"是否值得研究"的快速筛查，避免天天吹票式自我强化
- 出处：2023 整理帖评论引用

## M8 宏观利率分档法（择时的顶层过滤器）
- 企业贷款利率 6.5%+ = 高利率环境、4.5% = 中等、2.5% = 低利率
- 买股时机次序：高利率低估值 > 中等利率低估值 > 低利率低估值；低利率+偏高估值=风险区、低利率+高估值=高风险区
- "估值是艺术：市场利率 2.5% 时，没有下降空间的 5% 分红是低估；贷款利率 6.5% 时，5% 分红还是低估吗"
- 出处：2024-10-13、2024 发言精选（下）

## M9 完美底部信号清单（择时的落地检查表）
- 股价和估值都很低 + 经营良好 + 经济转好 + 货币宽松 + 分红很高 + 成交大幅缩量 + 无人愿卖 + 无获利盘 + 大股东回购
- 出处：投资理念和操作办法整理帖

## M10 周期双因子框架（大宗商品长周期定位）
- 内因：供需 + 供给端政策（能耗双控、产能审批、置换、关停）
- 外因：美元指数（强美元压大宗、弱美元催涨价）
- 本质：周金涛周期涛动论的实战化（整理号评价）
- 出处：十年体系复盘

## M11 做T分阶段量化（波段降本的操作手册）
1. 底部：正T（先买后卖），买100卖90或卖100（视仓位）
2. 中间：反T（先卖后买），吃 3-5% 差价
3. 相对高位：反T，5-10% 价差，卖100买50
4. 估值足够高：分批卖出不买回（神华分红率到 4-5% 即触发）
- 纪律：单次 ≤2% 仓位；被套就地卧倒；基本面不变才做T
- 出处：投资理念和操作办法整理帖

## M12 资产定性法（好资产的判断）
- 好资产 = 护城河/垄断/定价权/技术壁垒（有一个就足够）+ 别人亏钱他赚钱 + 无颠覆性替代者
- "好资产，不代表就是好价格"——定性之后仍要等低估
- 出处：投资理念和操作办法整理帖

> 使用提示：分析新标的时，优先套用 M3（盈利测算）+ M5（回本年限）+ M7（速评），跨行业比较用 M4，判断大时机用 M8/M10。所有方法输出时仍标注"观点规则化"。
