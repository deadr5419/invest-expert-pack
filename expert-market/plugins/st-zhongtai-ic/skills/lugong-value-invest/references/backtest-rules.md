# 可回测规则化清单（鹿鼎公观点 → 参数）

> **重要声明：以下所有规则均为"观点规则化"，即把鹿鼎公的公开观点转成可执行参数，未经任何历史回测验证。** 用于策略回测时须自行验证；参数存在版本差异的已并列给出。

## R1 选股因子（截面筛选）

| 因子 | 规则 | 版本/备注 |
|---|---|---|
| 上市年限 | ≥5 年 | 一致 |
| ROE | 连续 5 年 ≥15% | 一致 |
| 经营现金流/净利润 | ≥1.2 | 一致 |
| 股息率 | ≥4%（另一版本 ≥3%） | 版本不一，建议 ≥3.5% 起测 |
| 分红率 | 30%-50% | 一致 |
| 资产负债率 | ≤50% | 一致 |
| PB | <1 优先 | 一致 |
| 估值分位 | PE/PB 历史 30% 分位以下建仓、10% 分位内为极度低估 | 一致 |
| 实际控制人 | 央企/国资 | 一致 |
| 行业白名单 | 煤炭/水电/火电/电解铝/高速/国有大行 | 排除医药/科技成长/题材/民企小票 |

## R2 择时信号

- 估值分位 <30%（建仓区）、<10%（重仓区）
- 成交极度萎缩（如成交额处于 1 年最低 10% 分位）+ 右侧确认（公司回购/供需拐点）
- 宏观利率（可选）：企业贷款利率 >4.5% 时低估值才具吸引力；低利率+偏高估值 = 风险区

## R3 仓位规则（估值定仓）

- 极度低估（周期PE<8、股息>5%、分位<10%）：单只 ≤40%（仅长电破例）、板块合计 ≤35%
- 合理低估（PE 8-12、股息 3-4%）：单只 ≤20%
- 合理/高估（PE>12、股息<3%、分位>70%）：≤5% 或清仓
- 防御盘（公用事业类）常态约 40%；弹性仓 ≤5%；现金 2-5%

## R4 分批买入（四分资金）

- 25% 试探底仓（入低估区）→ 25% 回调加仓（-8%~-10%）→ 25% 恐慌加仓（系统性下跌至历史底部）→ 25% 机动现金（货币基金，极端下跌动用）
- 单只最多 3 轮加仓

## R5 加仓限制

- 允许：极度低估 + 基本面无变化
- 禁止：未到历史底部、浮亏 >15%、跌破 60 日线、板块仓位触 35% 上限、标的有结构性瑕疵（双周期/少数股东稀释）

## R6 做T/降本（可选增强模块）

- 单次做T ≤ 2% 总仓位；底仓不参与
- 低估段正T（先买后卖）价差 1-2%（一说 3-5%）
- 合理段反T（先卖后买）价差 3-5%（一说 5-8%）
- 高估段反T不接回，价差 8-10%+

## R7 退出规则

- 估值修复至合理区间（PE>12 / 股息<3% / 分位>70%）分批止盈
- 技术风控：跌破 20 日线减半仓、跌破 60 日线大幅减仓
- 基本面破坏（产能放开、负债率飙升、分红大幅下滑、垄断壁垒削弱）：无条件清仓

## 回测建议（工程侧）

- 数据：A股全市场 + 港股通（重点覆盖煤炭/电力/有色/银行/交运），2012 至今日频；分红用实际除权除息
- 基准：中证红利全收益、沪深300
- 度量：年化、最大回撤、年度胜率、换手率、分红再投贡献占比
- 敏感性：股息率门槛（3/4/5%）、估值分位阈值、做T是否启用（做T高频规则需 tick/分钟数据，成本敏感，建议先测不启用版本）
- 风险：规则化丢失了"垄断定性判断"这一非量化环节；小样本、幸存者偏差、风格时点依赖
