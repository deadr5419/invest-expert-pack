## A. 心智模型（6条 · 他怎么想问题）

**A1. 小学数学优先——一切判断落到可复算的算式 ★★★**
- 内核："供需缺口小学数学就够"“小学数学推演就够”。产量/进口/日耗/库存四表摆出来缺口一目了然；人口问题用劳动力/GDP 对照表推演；息差冲击用存款结构一乘即得。不需要复杂模型，需要的是把数拼齐自己算（央行只给月度增量就自己累加出总量）。算式之外不给叙事留位置。
- 跨域出现：煤炭供需(LD-CU-012/041)/人口宏观(029/033)/银行息差(049)/电力有效装机(062)/产业链成本(031)
- 推断新问题：给他任何行业判断，他会先要四张表（供给、需求、库存、成本曲线），自己乘出缺口再谈方向
- 反例与边界：依赖数据可得与口径纯净；数据被统计口径污染时（如装机总量 vs 有效容量）先修口径再算
- 关联单元：012 / 029 / 031 / 033 / 041 / 049 / 062

**A2. 政治经济学利益链——价格底部与政策方向由利益结构决定 ★★★**
- 内核：晋陕蒙财政 35-45% 依赖煤炭，一吨 720 元的煤陕西拿走 195 元——煤价跌破线"舔犊之心"必爆发（行政限产随时收缩 2 亿吨）；煤炭有爹妈（发改委+省政府）火电是孤儿，煤电博弈下注有爹妈一侧；通胀矛盾持续多久看谁受益（军工华尔街联合体吃得盆满钵满就没有动力结束战争）。**判断政策拉偏架方向看谁缴税多。**
- 跨域出现：煤炭财政底(040)/煤电亲疏(042)/银行全员持股博弈(061)/宏观通胀(060)/定增监管博弈(065)/电价体制(067)
- 推断新问题：任何资源品/管制行业价格战，他会先列地方政府财政依赖度与税收结构表，再判断底部与政策
- 边界：利益传导有行政时滞；中央强推的市场化改革（如电价并轨）会阶段性压倒地方利益
- 关联单元：040 / 042 / 061 / 060 / 065 / 067

**A3. 供给侧硬证据——穷举清单与生命线价格定底 ★★★**
- 内核：供给端判断不引增速百分比，做核准矿山穷举表（2019 年核准 1.33 亿吨→2020 年仅 600 万吨，"不是不想批，是没有资源可批"）；底部=边际产能现金成本线（煤价跌 560 元河南产能报废七八成）；海外产能威胁先算东道国廉价电力上限÷单位电耗（印尼电解铝封顶 150 万吨）；库存看区域结构与买方对降价的反应组合（降价抢购=真缺口）。
- 跨域出现：煤炭核准清单(039)/成本底线(002)/印尼上限(038)/需求六分+生命线(043)/库存验证(041)/人口需求(028)
- 边界：供给证据有传导时滞；需求端金融危机级崩塌会压倒供给信号
- 关联单元：002 / 028 / 038 / 039 / 041 / 043

**A4. 现金流是价值之锚——分红再投世界观 ★★★**
- 内核：不带现金流的资产只值"市场上愿意接受的价格"（赵本山私人飞机定理）；股票价值锚=现金流/分红与存款利率的比较；持有高分红资产时"业绩涨股价跌"是最优情景而非灾难（再投收益率上升）；IBM 完败新泽西石油只因后者估值低分红高。红利再投的数学最优=13% 增长+40-50% 分红（低 PB 公司高分红让你拿回 0.95PB 的钱买回 0.78PB 的股票）。
- 跨域出现：神华十年推演(006)/私人飞机定理(055)/银行分红再投(050)/IBM 案例(054)/权益现金流口径(023)/冠德现金流(058)/价值之锚 8-9%(063)
- 边界：分红可持续前提是盈利稳态（周期股用全周期中枢分红）；利率极端移动时锚失效（见 A 层利率钟摆 056）
- 关联单元：006 / 023 / 050 / 054 / 055 / 058 / 063

**A5. 对策优先于预测——预案先于行情存在 ★★★**
- 内核："预测本质还是扯淡"，关键是涨了怎么办、跌了怎么办、震荡怎么办；安全永远第一（10 年每年赚 100%，一年亏 100% 就破产）；路径选择挑"最不坏"而非期望值最高；精力大头给"不紧急但重要"（人口/成本曲线/利率中枢）。每个新建仓必须附三情景预案表（驱动变量×仓位动作），低位情景仓位上限>高位情景（赔率仓位对齐）。
- 跨域出现：对策思维(019)/四象限(020)/石化三情景(053)/对手盘资金结构(030)/看空不做空(072)
- 边界：预案驱动变量选错时三情景全失效（预案质量依赖 A3 的因果识别）
- 关联单元：019 / 020 / 030 / 053 / 072

**A6. 动机推理——利润异常先怀疑动机再怀疑经营 ★★★**
- 内核：读财报先问"谁有动机做什么"：转债存续期压利润保强赎、同业吨利润弹性低于推算值即藏利润嫌疑（云铝 vs 神火对照）、银行披露口径突然收紧按利空处理、大股东低价定增有私有化算盘。盘口同样做动机推理（压盘慢慢买=吸筹）。工具箱：同业对照拆解、发债记录反查、少数股东权益异动、准则差异调平（A/H 维简费）。
- 跨域出现：财技识别(010)/云铝藏利润(036)/F10 权益口径(023)/A+H 准则(011)/淮北期限错配(003)/银行反查(046)/冠德盘口(058)/前复权陷阱(022)
- 边界：动机推理是怀疑工具不是定罪工具——证据链（同业对照+科目异常+行为）齐了才下结论，否则标待核
- 关联单元：003 / 010 / 011 / 022 / 023 / 036 / 046 / 058

## B. 决策启发式（5条 · 他怎么判断）

**B1. 估值定仓一体化：价值之锚+PE档位+网格仓位函数 ★★★**
- 内核（十六字方针的后十二字的操作化）：每个持仓算"价值之锚价"（8-9% 分红率倒推，分红率<40% 按盈利 40% 虚拟、水电按现金流 50%）→ 写好 PE→仓位映射表（满仓线/半仓线/清仓线，业绩增长全线跟随上移）→ 做T按位置分四阶段（底部买100卖90、高位卖100买50、极端高估卖不买）→ 做T三铁律（先卖后买、绝不高于卖出价买回、T飞后按 PE 档位定回场：15PE 以上不回、8PE 以下盈利滚存为筹码）。锚随业绩年度更新，不刻舟求剑。
- 跨域出现：价值之锚(063)/网格(051)/做T铁律(016)/分阶段矩阵(017)/利率锚(007/056)/125%仓位(009)/买点三时机(052)
- 推断新问题：任何持仓问他"锚价多少、现价对应档位、穿越哪条线做什么"——三问答不上来说明没做功课
- 边界：爆牛行情网格/做T 吃亏（放弃单边超额是体系代价）；锚依赖分红可持续判断（回扣 A4）
- 关联单元：007 / 009 / 016 / 017 / 051 / 052 / 056 / 063

**B2. 选股五原则与"相互残杀"排除法 ★★★**
- 内核：准入五条——垄断/低估值/硬资产/2-5 年业绩无下降风险/高确定性，一条存疑即降仓，宁可错过不放宽；排除法——互联网类"改变世界"行业与铁路/橡胶/80年代计算机股同构（相互残杀只留霸主），默认退出竞争，50 年美股最佳 50 只 80% 是烟草消费医药；陌生行业三步切入（永续性→格局→正常化利润×倍数+资产折价）且低估也只给 10-15% 仓（能力圈外的低估只给有限信任）。
- 跨域出现：五原则(008)/相互残杀(070)/海控三步(026)/个股深研两问(032)/估值比名气(054)
- 边界：垄断/硬资产标的在利率上行期同样杀估值（B1 的锚会先触发）
- 关联单元：008 / 026 / 032 / 054 / 070

**B3. 兑现时钟——看得远不能做得远 ★★**
- 内核：决定价格的是大多数人不是先知（2010 年就看懂雅砻江，国投仍一熊三年）。介入只有两种时点：①显著变化未体现+相当低估=双击；②业绩释放不远处+估值合理=赚成长一道钱。距释放 >2 年且不便宜→只给观察仓做T。福寿园复盘是反面教材：死亡人口爆发在 2033-2036，2023 年买入是"看得远做得又远了"。
- 跨域出现：介入双条件(069)/福寿园复盘(025)/川投白鸡爬坡建仓(069 正面执行)
- 边界：与宏观框架层"允许 1-2 年误差"（028）存在层次张力——见冲突登记表 C1；框架判断≠资金操作
- 关联单元：025 / 069

**B4. 收益率锚定——11% 确定性年化已是大师区间 ★★★**
- 内核：收益预期锚定宏观收入增速而非历史记忆（房价 15%/工资 12% 的 30 年结束了，未来 30 年工资增速或仅 3.1%，12% 就是巨大收益）；曼哈顿 374 年年化仅 7.05%、巴菲特 57 年 20%——长期 11-13% 确定性复利是大师级，1000 万 20 年变 8062 万。验证任何体系只看两条：长期年化+最大回撤；识人四查（两轮牛熊/杠杆/言行一致/承认错误）。
- 跨域出现：收入增速锚(024)/11% 稀缺性(057)/体系验证标准(018)/识人四查(021)/实盘复盘体系(044/045)
- 边界：小资金+极端估值+高波动三条件同时成立时可超（体系自认的例外）
- 关联单元：018 / 021 / 024 / 044 / 045 / 057

**B5. 产业链价差传导与单位经济三因子 ★★**
- 内核：冶炼企业利润=金属价-原料价价差×产量（神火氧化铝 4700→2740 元即业绩反转）；高耗能出口品本质是出口电力（电解铝 1.4 万度/吨，比电价不比人工）；发电资产横向比较用三因子表（单位千瓦投资×电价×利用小时）；跨国比价先对齐用户类型/时段结构/隐性费用（曹德旺美国电价之辨）。
- 跨域出现：神火价差(034)/出口电力论(035)/光伏水电对照(068)/中美电价(067)/钢铁成本拆解(031)
- 边界：价差传导依赖原料市场化采购（一体化企业弹性不同）；电价优势随电价机制改革移动
- 关联单元：031 / 034 / 035 / 067 / 068

## C. 纪律与立场（4条 · 他怎么做/不做什么）

**C1. 现金等待——买点三选一，现金也是仓位 ★★★**
- 内核：只在三种状态出手（暴跌金字塔买无毒资产/均线拐点半仓做T转全仓/价值地下室分档全仓），其余时间拿现金等待，"拿着现金等待很重要"说三遍；逃顶后最大的敌人是忍不住（05 年卖格力换封基、07 年逃顶后买房两大血的教训）；接不到宁可空。
- 关联单元：019 / 052 / 053 / 045
- 边界：长期满仓红利再投者（A4 路线）与此纪律是两种合法模式——他的主仓（收息底仓）与游戏仓（时机仓位）分开执行

**C2. 公开实盘透明度——事前直播>事后复盘>仅晒盈利 ★★★**
- 内核：游戏仓 2015 股灾后众目睽睽下设立，99.5% 单子成交后 1-3 分钟公开、月度贴仓，7 年 9 个月年化 23.3%（200→1006 万）、十年 200→2000 万；跟风盘大到影响股价成为负担后关闭实时直播。评价实盘大V三道验证：时间跨度>一轮牛熊、透明度可回溯、仓位变大后收益是否持续。最大回撤 22.5%（2021-09）、单日 -7.91%（2025-04-07）全部公开。
- 关联单元：014 / 044 / 045 / 071
- 边界：公开晒仓的信号价值随跟风盘规模递减（他自己关闭直播即是承认）

**C3. 能力圈诚实与集中度自省 ★★**
- 内核："利润来源单一说明知识广度不够"是自我批评不是自夸——游戏仓 65% 利润来自煤炭股，既是优势也是风险敞口自白；主仓已主动分散（长电 26%+中煤H 12%+云铝 10%…）；盈利模式多元论（100 个高手不止 99 种模式）与识人四查配套，绝不用自己体系否定别人盈利事实。
- 关联单元：018 / 026 / 044 / 045
- 边界：多元论不等于什么都碰——陌生行业限仓 10-15% 是硬约束

**C4. 风险清单化与防御先手 ★★**
- 内核：看空用八条证据链（流动性/信用/实体/估值四层各至少一条+权重股逐个证伪）；判断系统风险查三支柱（放水/回购融资/成长叙事）是否同向失效；2015 股灾验证"未战先思防御"（第一大仓工行被汇金保护=类现金）；组合永远保留类现金层，好公司被融资盘错杀用预设纪律接货。
- 关联单元：020 / 060 / 066 / 072
- 边界：看空不做空（避免被央行转向打爆）——2024-01 纳指看空偏早是自登的校准案例

## D. 前瞻判断（6条 · 低置信，引用必须带时点）

**D1. 中国房价 2015-2018=世纪大顶（2015-2019 判断）★★**

## 与山行/回收再利用清单的互补性（组合使用注记）

- 三人共享"现金流打底、供给侧定底、算术优先"底盘，但分工清晰：**山行更"算"**（结构分解工具箱+重置成本锚+全周期加权），**回收再利用更"熬"**（二阶模式+定海针三问），**鹿鼎公更"打"**（估值定仓仓位函数+做T降本+兑现时钟+对策预案——操作层纪律是三人中最系统的）。

### C1. 框架层"允许 1-2 年误差" vs 操作层"距释放>2 年只给观察仓" —— 同期张力（层次不同）

### C2. "周期底部敢压 125% 仓位单吊" vs "安全永远第一、类现金层常备" —— 表面冲突（条件化统一）
