# 行业分析与空间测算方法论（强制执行）

> 目的：杜绝"数据陈列无逻辑"（facts-first）与"TAM 空炮"两类行业分析通病。行业分析不是资料汇编，是**一条可辩驳的因果链 + 一组可验证的空间测算**。2026-08-12 由用户主导探讨定稿（含外部框架调研 + 专业研报对照：华鑫宠物/广发泳池/伯恩斯坦 Figure TAM 质疑）。

## 一、行业全景：thesis-first 因果链（v2）

**强制结构**，行业总览章按此组织，缺一环视为不合规：

```
主线 thesis：一句可辩驳的主张（先立论点，不先报数据）
  ├─ 行业核心指标锚：3-5 个"这个行业靠什么指标运行"（借鉴 competitive-analysis Step0）
  │    例：创新药=BD交易额/III期成功率/获批数量/销售峰值；SaaS=ARR/NRR/LTV-CAC
  ├─ 产业定位层（站高）：发展阶段（生命周期+渗透率）/ 比较优势（钻石模型）/ 全球分工（微笑曲线·GVC），见下方「产业定位层」
  ├─ 需求侧 → 供给侧 → 成本侧（三侧必须各自成链，见铁律）
  ├─ 传导：价值链利润池（钱从哪来到哪去）+ 盈利模型 + 估值锚切换
  ├─ 兑现验证：证据链（已发生的硬事件）
  ├─ 可及市场：可投资空间链（见下）
  ├─ 价格机制 → 政策周期
  ├─ 落到标的排序（竞争格局 + 护城河）
  └─ 证伪信号：什么会推翻这条主线（防叙事自我强化）
```

**写作铁律**：
- 开头必须有主线 thesis；禁止直接报数据
- 每段回答上一段的"所以呢"，禁止四段平行
- 行业空间禁止报"全球 1.6 万亿"式宏观 TAM（与标的盈利脱节）——按"可投资空间链"测算
- **成本侧必须成链**（2026-08-12 电解铝教训）：任何行业都要回答"成本主体的优势来源"并给完整逻辑链（如电力洼地：国内电价低 → 成本优势 → 海外高能源成本压制海外产能；互联网：流量/算力/获客成本），禁止只放单点成本数据（如"氧化铝 2699 元"）而不讲机制
- **需求侧必须给结构性结论**（2026-08-12 电解铝教训）：回答"需求结构怎么变、波动性变大还是变小"（如"地产主导 → 制造业+新能源+出口，周期波动变小"），禁止只列单点数据（如"光伏 405 万吨"）而不下结论
- **逻辑完整性自检（生成后必过，内容 QA 前置）**：按行业列出逻辑块清单（如电解铝=供给刚性/成本让利/需求韧性/出口），每条必须完整"数据 + 机制 + 证伪信号"三件套；专家/大V 的关键行业逻辑（如"护城河=国家本身"）必须上移为行业逻辑层输入，禁止只躺在大V观点映射表里；缺链即补，自检通过才交付

### 产业定位层（站高，2026-08-13 新增）

> 行业分析先"站位"再"拆链"：回答这个行业在中国/全球分工中的位置与发展阶段，避免"只见树木不见森林"。**适用门禁**：只对"成长期新兴产业（渗透率约 5–65%）+ 行业代表组合（指数成分/龙头组合）"触发；成熟/衰退期、单票 α、平台型/单品种/覆盖率≈100% → 显式声明"不适用"并转对应方法（衰退期转 comps-valuation「幸存者终值法」）。

三维度（用成熟理论术语，禁止自造词）：

1. **发展阶段定位**（产业生命周期 + 渗透率 S 曲线）：行业在中国/全球处于引入/成长/成熟/衰退哪一阶段？渗透率在哪个区间？——判断"为什么是现在"（成长早期看空间、后期看盈利）。
2. **比较优势**（波特钻石模型四要素）：生产要素 / 需求条件 / 相关与支持产业（产业集群）/ 企业战略与竞争——中国在这四个维度各强在哪、弱在哪？
3. **全球分工位置**（微笑曲线 / 全球价值链 / 雁行模式）：中国在该产业价值链的哪个位置（研发/制造/品牌）？正在向哪移动（承接转移 → 弯道超车 → 反向输出）？

## 二、可投资空间链（行业空间测算的强制口径）

```
全球/可比市场空间（国内+海外分测，不一锅端）
  → × 中国可及份额（产业禀赋：凭什么中国公司吃到——成本/技术/牌照/替代逻辑）
  → × 上市公司覆盖率（证券化率：代表多少）
  → 收入空间 → 市值空间
  → ⑤ 常识校验（反向验算，链条越长越强制）
```

**行业代表组合（指数成分/龙头组合）用自上而下**：行业总空间 × 中国可及份额 × 龙头覆盖率，禁止逐票加总个股市场空间（个股 α 让位于行业 beta）。

**市占率口径**：市占率用**权益口径**（对行业去重总额，去重自洽）——"全口径签约销售"含合作项目重复、会高估真实份额，仅作"操盘规模"参考；代建/服务等非核心业务不计入。个股估值见 comps-valuation「销售口径铁律」用权益口径。两口径禁止混用。

### 行业特殊性检查清单（每环怎么算，行业不同）
| 环节 | 检查问题 |
|---|---|
| 市场定义 | 这个行业的"空间"到底是什么？市场规模？产能×价格？装机×利用小时？ |
| 份额驱动 | 中国公司凭什么吃到？成本/技术/牌照/国产替代/出海 |
| 覆盖率 | 上市公司代表多少？像长江电力≈100%，还是创新药部分覆盖 |
| 结构校验 | 跨市场类比可不可比？（人口密度/支付结构/监管/渗透率阶段） |

### 空间测算门禁（四检查，类比 comps Phase 0——不适用就显式写"不测理由"）
| 门禁 | 检查 | 不通过处置 |
|---|---|---|
| ① 转化路径 | 行业空间能否转化为该公司收入（覆盖率/渗透率逻辑） | 转自下而上（产能/订单/管线） |
| ② 驱动归属 | 公司增长是行业驱动还是自身变量驱动 | 自身驱动（如 CXO 订单）→ 不测 |
| ③ 叙事依赖 | 市场估值是否依赖"行业空间大"（渗透率故事） | 不依赖 → 可不测 |
| ④ 边界清晰 | 行业边界是否可定义 | 平台型（边界自定）→ 不测 |

典型不测：长江电力（覆盖率≈100%）、CXO（订单驱动）、科伦博泰（单品种）、平台型（边界自定）。

## 三、数据纪律（每环数据怎么拿、怎么验）

1. **数据分层标注**：硬（财报/公告/交易所）＞ 中（行业协会/海关）＞ 软（咨询预测/卖方转引）；软数据必须标来源+日期+`[待核]`，硬数据才可直接引用。
2. **生理基数自下而上验算**（最强纪律）：引用任何空间数据前，先用量×价×渗透率自己算一遍——**优先从"刚性物理/生理基数"出发**（猫每天吃多少、渗透率多少、泳池数量×渗透率×更新周期），比引用咨询公司 TAM 更硬、更难注水。算不出来=口径不清=标[待核]。
3. **多源交叉**：两个独立来源对得上才引用；对不上标[待核]。
4. **敏感性承载**：任何一层数据不准都靠敏感性兜底——渗透率/单价/份额 ±20% 对最终空间的影响。单点预测永远是假的。
5. **渗透率类测算结构**：基数增速低时，空间全在渗透率——明确"增量看存量渗透率，而非基数增长"（广发泳池案例）。

## 四、常识校验（反向验算 + 质疑式测算姿态）

链条每多一环误差相乘放大（±20%×4 步≈±60%），**算完必须反向验算**：

| 校验 | 做法 |
|---|---|
| 量级检验 | 结果占全球 GDP 比例、与可比国家现状比，量级合不合理 |
| 隐含参数反推 | 从结论倒推渗透率/人均/市占率，看隐含值荒谬否（最有力） |
| 现实锚点优先 | **测空间前先答"当下渗透率/已装量是多少"——结论目标 ≤ 现实状态则推导作废**（海康案例：2019-2020 中国已遍地摄像头、人均已超美国，推导目标≤现实仍未发现） |
| 时间检验 | "还有很大空间"喊了多年兑现了吗 |

**姿态升级（伯恩斯坦式）**：常识校验不是收尾检查，是**全程质疑**——从第一环就假设"市场共识的空间可能是错的"，逐环拆解（伯恩斯坦《为何质疑万亿美元市场？Figure TAM 深度分析》即此风格）。

## 五、案例库（对照教材）

- ✅ **创新药**（可投资空间链正确示范）：全球市场（国内+海外分测）× 产业优势（BD/出海）× 上市公司覆盖率 → 收入/市值空间
- ❌ **海康摄像头**（类比谬误+无视现实）：人均对标外推忽略人口密度结构差异，且不查当下已装量（2019-2020 人均已超美国）——**现实锚点优先可拦下**
- 📖 **专业研报对照**：华鑫《宠物子赛道：市场规模与企业空间测算》（生理基数自下而上 + 格局→企业空间，与可投资空间链同构）；广发《泳池机器人》（存量×渗透率×更新周期，渗透率驱动）；伯恩斯坦《Figure TAM 质疑》（质疑式测算）。原稿在 `deliverables/行业空间测算方法论/`。
