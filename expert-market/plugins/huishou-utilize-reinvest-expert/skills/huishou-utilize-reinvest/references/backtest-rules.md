# 回收再利用 · 可回测规则化清单

> 用途：把他的观点转化为可量化规则供回测验证。**全部未经回测验证**（观点规则化），参数存在版本差异时并列给出。

## R1 二阶模式买入规则（资源股）
- 触发：商品价格中枢抬升（供给收缩/需求增长）但股价较前期高点深度折价（市场盯短期报价）
- 参数：价格中枢（如铝22000-25000）确认上移；股价未定价长期基本面
- 卖出：价格中枢逻辑破坏（供给恢复/需求证伪）
- 来源：2026-06-24《二阶模式》【未经回测】

## R2 股息保底估值规则
- 估值锚：稳定分红股 = 预期股息率 + 分红率 + 盈利预测
- 买入线：股息率≥4%（"200亿以下有保底"=4.125-4.5%股息）
- 参照系：长电股息率3-3.3%、分红率70-90%为收息股坐标
- 来源：2024-03-25 招行分红三问 / 2024-07-10 中糖200亿保底【未经回测】

## R3 电-铝轮动规则（组合层）
- 触发：电解铝与综合电力仓位轮动，哪边涨多减仓加另一边，都涨多就走人
- 基线：2024-09 调仓 铝/火绿电/糖 65/15/20 → 30/50/20
- 来源：2024-10-08 牛市计划【未经回测】

## R4 煤电铝三角形规则（组合构建）
- 选股池：电力（国电）+ 电解铝（神火/中铝）+ 煤炭（电投），股息≥4%
- 配置：国电7成（最大头），其余分散
- 来源：2025-04-10 首发名单【未经回测】

## R5 计提识别规则（财报质检）
- 异常信号：收入/毛利创新高但净利暴降（辽宁厂案例）→ 查账龄覆盖/单项vs组合计提
- 健康阈值：坏账准备 ≥ 2年以上账龄应收 × 50%（类拨备覆盖率109%）
- 来源：2024-08-31 / 2025-08-18【未经回测】

## R6 胜率/赔率权衡规则
- 高胜率低赔率（国电型）：底部有保底（股息+成长），重仓
- 高赔率低胜率（困境反转型）：轻仓或观察
- 决策："先求不败而后求胜"
- 来源：2025-03-19【未经回测】

## R7 江苏电量电价算法（地方电力参考）
- 公式：燃煤机组电量电价 = 年度长协×60% + 月度竞价×20% + 现货×20%
- 案例：344.85×60% + 312.8×20% + 280×20% = 325.47 元/MWh（vs 2025年343.84 差1.8分+容量电价补齐）
- 来源：2026-01-28 国电江苏算法参考【未经回测】

## 回测注意
- 该大V记录期仅 2023-2026（3年），**跨越完整牛熊周期不足**，规则外推需谨慎
- 观点存在演进（中糖300亿→200亿、持仓集中度），回测参数需按时间段分段
- 所有规则为"观点规则化"，非其本人回测结果
