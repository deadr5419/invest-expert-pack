# Report Skeleton · 报告骨架与版式标准（强制执行）

本技能是**所有深度研究报告的唯一结构标准**。撰写、组装、审查报告时必须加载，章节结构以本技能的模板为准；其他技能（initiating-coverage、earnings-analysis 等）内部的报告模板仅作内容颗粒度参考，**不得**用其章节结构替代本骨架。

## 铁律

1. **必含章不可缺省、不可换序**——缺章或换序视为不合规，主任审查直接打回。
2. **允许加章**：扩展章（如"大V框架逐条校验"）放在第七章（估值）之后，编号用"七·附"，不打乱主骨架。
3. **编号体系统一**：W1 单篇用"一、二、三…"；W2 系列文件序用"00/01/02…"，篇内用"一、二、三…"。禁止①②③圈码、0-6 阿拉伯数字等混用。
4. **前置三件套必备**：封面页 → 目录页 → 结论先行·评级总览表（格式见模板）。
5. **版式统一**：HTML/PDF 产出必须使用 `templates/report-style.css` 与 `templates/report-shell.html`，不得另起样式。

## 写作与命名规范（2026-08-12 补充）

1. **公司名称首次出现必须用全称 + 代码**（如"中国生物制药（01177.HK）"）；**禁止自造/口语化简称**（如把"中国生物制药"写成"中生制药"——属错别字级不规范）。后续行文可用市场通行简称（如"中国生物制药"或确认无歧义的简称），拿不准一律用全称。
2. 缩写与代码统一：代码带交易所后缀（.HK/.SH/.SZ），首次出现带全称。
3. 数据/观点/结论用词按本技能"深度下限"执行，禁止口语化表述进入正式报告。

## 呈现版报告结构（2026-08-13 新增：分析框架不变，只改呈现形式）

> 报告正文按专业研究报告的阅读逻辑呈现（先结论 → 再逻辑 → 再拆解 → 再估值 → 再风险）。**分析动作不变**——估值穷举筛选、数据核验、大V观点映射、冲突常识裁决、可比对照全部照做；但**呈现时下沉**：不占章节标题、不用内部词，改用标准研报语言。

### W1 单标的（分析十章 → 呈现八章）

| 呈现章节 | 内容 | 对应内部动作（下沉） |

| 二、投资逻辑 | thesis：估值锚 / 市场错在哪 / 证伪信号 | — |
| 三、公司概况 | 业务结构 / 商业模式 / 治理 | 公司画像 |

| 五、经营与财务分析 | 财务拆解 / 盈利质量 / 线索深挖 | 财务拆解与线索深挖 |

### W2 系列（呈现版）

- **00 行业总览**：投资要点 → 行业全景（含产业定位层）→ 竞争格局 → 市场观点与多空 → 行业评级与配置
- **个股简版**：投资要点 → 公司概况与成本结构 → 经营与财务分析 → 盈利预测 → 估值与目标价 → 投资观点与风险
- 大V观点融入"市场观点与多空"，不单列"大V汇总与冲突裁决"章；数据核验记录下沉为各章内标注来源 + [待核]

## 深度下限（防"薄版"）

以下内容为每篇报告的**最低颗粒度**，缺少即视为深度不达标：
- 显式假设表（盈利预测与估值的所有关键参数）
- 估值方法穷举 + 筛选/排除理由 + 主锚测算 + 交叉验证 + 压力测试
- 情景分析（乐观/中性/悲观，"预期不变"也须显式声明）
- 高重要性线索推演（决定盈利与估值方向的关键线索取前 2-3 条，**无关键可跟踪线索则不推并显式声明**：驱动因子 → 因果链路径[依据→推断→结果传导] → 影响量化层层落至估值[盈利增量/变化后盈利/目标价] → 跟踪信号与证伪；只列路径不作概率判断，信息不足可补充采集）
- 可比对照：自身历史分位 + A/H 或中外同业
- 风险清单（含触发条件与观察信号）+ 催化剂日历 + 待核清单

## 内容逻辑 QA（2026-08-12 电解铝教训新增，生成后强制，先于排版 QA）

> 排版 QA（pdf-typesetting）管"好不好看"，**内容逻辑 QA 管"有没有内在逻辑"**——两者都是交付门槛，缺一不可。

行业全景章节（W2 第二章 / W1 第三章）生成后，必过以下自检，缺链即补：
1. **逻辑块完整链**：按行业列出逻辑块清单（电解铝=供给刚性/成本让利/需求韧性/出口；创新药=定价切换/专利悬崖/管线/支付；煤炭=供给/成本/需求…），**每条必须有"数据 + 机制 + 证伪信号"三件套**——禁止只列指标数据（facts-first）或只报宏观 TAM；
2. **成本侧成链**：成本主体的优势来源是否给了完整机制链（如电力洼地 → 成本优势 → 海外高能源成本压制海外产能），而非只放单点成本数据；
3. **需求侧结构性结论**：是否回答了"需求结构怎么变、波动性变大变小"（如"地产主导 → 制造业+新能源+出口，周期波动变小"），而非只列单点数据；
4. **大V/专家逻辑上移**：专家/大V 的关键行业逻辑（如"护城河=国家本身"）是否上移为行业逻辑层输入，而非只躺在大V观点映射表里孤立引用；
5. **证伪信号**：每条逻辑块是否有"什么会推翻它"的显式说明。

## 评级体系（隐含回报 + 催化确定性，2026-08-12 定稿；指引层而非算法层）

> **定位**：评级是基本面分析的**收尾指引**（给读者一句话结论），不是公式输出。**估值本身是艺术**——目标价是保守口径（反乐观纪律压出的，低于卖方中位是常态），评级只用它算隐含回报，**不叠加概率/赔率/加权**（那些要么是拍的、要么是多余翻译）。不确定性用"暂不评级"诚实表达，不拍数字。
>
> 所有深度报告结论先行·评级总览表与个股评级按本体系落。`comps-valuation` 产出目标价后，接本流程。

### 评级定义（标准研报用语，内部档位见映射表）

| 评级 | 隐含回报门槛 | 正式定义 |
|---|---|---|
| **强烈推荐** | ≥ 25% | 保守目标价下隐含回报显著跑赢宽基（约 2.5 倍），且核心催化已落地 |
| **增持** | ≥ 10% | 保守目标价下隐含回报跑赢宽基（10% 基准线），催化确定性较高 |
| **中性** | -5% ~ 10% | 隐含回报在推算误差带内（估算不一定准，微亏也算中性） |
| **减持** | < -5% | 明显跑输宽基，或下行显著大于上行 |
| **回避** | 目标价 < 现价 | 负隐含回报，核心逻辑受损 |
| **暂不评级** | 催化不必然（内部细分：期权型=隐含回报≥25%；待定=<25%） | 节点未落地前不评方向；期权型小仓位跟踪，待定等落地重评 |
| **无法评级** | T 给不出 / 太远（超 5 年） | 给目标空间 + 提示风险，不给年化，不评方向 |

### 计算口径（唯一输入）

- **隐含回报（年化）=（目标价中值 ÷ 现价 − 1）÷ T**；T = 估值兑现期（年），由估值思维决定——现值思维（成熟期）T=1；终局思维（成长/衰退）T=终局兑现年数，由**多方研报 + 可比经验 + 历史经验多重交叉确认**，不好确认就给范围、用**保守 T（上限）算隐含回报做压力测试**（保守 T 下仍 ≥10% 才值得投资）。**T 上限 5 年**；超 5 年或研究完仍给不出 T → 给空间 + 提示风险，不给年化，归"无法评级"。
- 目标价一律采用**保守口径**（见 comps-valuation 反乐观纪律），**所有评级（含暂不评级）都必须给目标价**（暂不评级目标价 = "兑现情景"参考价）
- **催化确定性**（代替概率，是非判断不拍数）：核心催化是否"随时间流逝必然兑现"？已落地事实（BD 已签/III 期已阳性）= 确定性高；二元事件（获批/被拒）或可能不发生的事（BD 谈判/续作）= 待催化 → 暂不评级
- **零概率、零赔率、零加权**——不确定性 = 诚实的"暂不评级"

### 行业→个股落地（置信度颗粒度匹配，2026-08-13 新增）

> **元规则**：行业判断落地到个股，按置信度颗粒度匹配——**beta 进组合、α 打折扣、确定性极高才直通单票**。禁止把"行业 beta"直接当成"个股 α"。

1. **beta 进组合（W2）**：行业能说清的（会出清、幸存者集中）用**组合层面**评级与配置承载，用一篮子分散"谁最终胜出"的个股不确定性，不强制逐票给高置信结论。组合评价独立成章：可印证 thesis + 承载清单 + 组合空间 + 印证信号（组合空间测算用"组合幸存者终值法"，见 comps-valuation「幸存者终值法」）。
2. **α 打折扣（W1）**：单票押"谁胜出"需折价——个股映射确定性 高/中/低 → 折价 0–10% / 10–20% / 20–30%（重点在提示非精确），报告须显式写"因个股映射不确定性折价 XX%"。**折价只打目标价（买点锚），不打卖点（离场锚）**——折价针对"个股能否兑现"的不确定性，打在保守目标价上留安全边际；卖点是"已假设兑现"的乐观值，再打折＝自相矛盾、且会压低离场位错失上行。
3. **直通前置（四硬指标）**：仅同时满足①行业是慢变量（需求稳定/技术不颠覆/格局不洗牌——地产洗牌、AI 颠覆、创新药获批二元均属快变量，天然无"确定性极高"单票）②行业地位不可替代（市占率居前 + 多年稳定 + 供给侧稀缺/牌照/心智壁垒）③穿越周期记录（至少一个完整周期地位不被动摇）④盈利韧性（行业最差年份仍盈利、现金流为正）四项全过，才可把行业判断直接映射为单票结论；否则一律走折价（见第 2 条）。

### 评级理由话术模板（专业研报风格）

> 考虑到【催化落地状态】；隐含回报【X%】（保守目标价中值，年化，T=Y 年）；核心催化【已落地/待落地】，给予【评级】评级。

### 评级总览表模板（标准研报用语）

```
证券简称 | 代码 | 评级 | 现价 | 保守目标价中值 | 隐含回报(年化) | 评级依据
```

- 两锚分列，不设目标价区间：**保守目标价中值**（评级锚，唯一计入评级、算隐含回报）与**卖点**（独立离场锚，乐观盈利×中性倍数，不改评级）并列呈现；现价/目标价为当地货币（HKD/CNY）
- 评级依据 ≤ 20 字，写明核心逻辑与催化确定性
- 暂不评级在评级依据后注明"兑现情景参考价 X"或"等节点落地重评"

### 卖点（乐观情景参考价，与保守目标价对称的离场锚）

> 定位：保守目标价回答"买点"——悲观/中性假设下的合理价值，现价低于它才有安全边际。本体系再补对称的另一端**卖点**——可落地乐观情景下的价值上沿，回答"涨到哪该减仓"。**乐观不打满、只计入可落地情景**，这是卖点与"全面乐观"的分界。

| 条款 | 内容 |
|---|---|
| 定义 | 卖点 = "可落地乐观情景"下目标公司的合理价值上沿。股价到达/接近卖点，意味着可落地乐观预期已被市场计入，下行风险开始大于上行空间，为**减仓/离场参考位**，非买入点 |
| 对称关系 | 买点锚 = 保守目标价中值（算年化空间、定评级，现有逻辑不变）；卖点锚 = 可落地乐观情景价值上沿（标"乐观打满"位置）；**两锚分列呈现，不合并为目标价区间** |
| 可落地判定 | 乐观情景只计入四档中的前两档：①已落地事实（已签订单/已投产产能/已公告涨价/已兑现政策）→ 计入；②有时间表+里程碑、大概率兑现（在建产能按期投产/审批末端政策）→ 计入并标"待落地"。③二元未决（获批被拒/BD 谈判/续作）→ 不计入（评级已归观察档，卖点同理不提前计）；④纯叙事/远期想象（全球 TAM/十年格局）→ 一律不计入 |
| 估值方法 | 卖点 = 可落地乐观情景盈利 × **中性倍数**（历史中位/25-75 分位）。**禁止"乐观情景 × 乐观倍数"双重放大**，违反反乐观纪律；测算同保守目标价，过敏感性可复算性（同股本同汇率） |
| 评级关系 | 卖点**不改变评级**（评级仍由保守目标价中值算年化空间得出）；观察档"兑现情景参考价"口径与卖点一致，卖点即其上沿；**卖点不打个股映射折价**（折价只作用于买点锚） |
| 触发纪律 | 股价触及卖点 → 提示减仓，**不因"还能涨"滚动上调卖点**（滚动上调 = 卖点失效）；仅当出现新的可落地事实（乐观情景升格为已落地）才允许重估 |
| 适用性门禁 | 卖点**非必然动作**：存在可落地乐观情景（增量催化/成长期权）才给；纯收息/成熟防御/无期权 → 不给卖点，显式声明"无有意义的乐观情景" |

### 乐观·推演·卖点 联动与适用性门禁（有意义才触发，无意义显式声明）

> 乐观情景、高重要性线索推演、卖点，是**同一条"乐观→价值"链的三个截面**，且三者**都不是必然动作**——与行业空间测算门禁、comps Phase 0 同理：**有意义才触发，无意义则显式写"不触发理由"**，不是每个标的都做全。

**联动链条**：可落地乐观情景（假设层）→ 高重要性线索推演（路径层）→ 卖点（定价层）。三者同源：卖点 = 推演乐观路径落到估值的顶；推演 = 可落地乐观情景的兑现路径；乐观情景 = 只计可落地的乐观。

**适用性门禁（三检查，不满足即不触发该动作）**：

| 动作 | 触发条件（有意义才做） | 不触发处置 |
|---|---|---|
| 乐观情景 | 存在可落地/有里程碑的乐观驱动（增量催化、成长期权） | 无增量催化（纯收息/成熟防御/无期权）→ 不编乐观情景，显式声明"无有意义的乐观情景" |
| 线索推演 | 存在决定盈利/估值方向、且可跟踪的关键线索 | 基本面稳定、无关键变量 → 不推，显式声明"无值得推演的关键线索" |
| 卖点 | 存在"乐观打满显著高于保守目标价"的空间 | 乐观与保守无实质差异（纯价值/无成长溢价）→ 不给卖点，显式声明"卖点与保守目标价趋同，不单独标注" |

**哲学一致性**：三者的省略，与行业空间测算门禁的"不测理由"、comps Phase 0 的"降级理由"同源——**"不做"同样是显式决策，要写进报告，而非遗漏**。

### 术语表（报告附录必备）

| 术语 | 正式定义 |
|---|---|
| 保守目标价中值 | 主锚测算（DCF/rNPV/正常化盈利，反乐观纪律压出）的保守口径；评级锚，唯一计入评级 |
