# 可比公司估值（Comps Valuation）

## 功能说明

构建和分析可比公司估值表，通过对比同业公司的估值倍数（P/E、EV/EBITDA、P/B、P/S、EV/Revenue 等），对目标公司进行相对估值定价。

## 估值思维第一道分叉（终局思维 vs 现值思维，2026-08-13 新增）

> 估值的第一步不是选倍数，而是先判断**行业未来会不会发生结构性巨变**——"现在"的财务数据只有在行业不变时才能线性外推。

| 行业状态 | 会不会巨变 | 估值思维 | 方法 |
|---|---|---|---|
| 成长期（渗透率 5–65%） | 会（向上爆发） | 终局思维 | 终局空间 × 渗透率 × 份额（配 industry-analysis-method 产业定位层） |
| 成熟期（稳态） | 不会 | 现值思维 | 当前正常化盈利 / 股息 / 现金流 |
| 衰退期（出清重构） | 会（向下重构） | 终局思维 | 幸存者终值法（见下） |

- **会巨变**（成长 / 衰退）→ 终局思维：先定终局状态 → 判断路径与幸存者 → 倒推现值，禁止用当期失真数字外推。
- **不会巨变**（成熟稳态）→ 现值思维：当前 ≈ 终局，正常化数据直接定价。
- 终局思维最大的坑是"终局假设拍太乐观"——全程受「反乐观纪律」约束（保守口径 + 区间 + 反锚定）。

## 工作流

### Phase 0：可比法适用性门禁（强制第一步，不适用则降级）

开始任何 comps 之前，先过四道检查，**全部通过才进入 Phase 1**：

| 门禁条件 | 检查内容 | 不通过的处置 |
|---|---|---|
| ① 业态同型 | 是否存在商业模式一致的成熟对标（同业态，非仅同赛道） | 全球无对标 → 降级 rNPV / 历史自身分位 |
| ② 阶段可比 | 对标与目标公司成长阶段相近（商业化兑现期/盈利爬坡期，禁止成熟蓝筹比成长期） | 阶段差距过大 → 降级 DCF / 自身分位 |
| ③ 口径可核 | 收入/盈利口径可比且数据可溯源（会计准则差异、PS 用产品收入还是总收入） | 口径不可比 → 降级并说明理由 |
| ④ 周期位置 | 非周期股顶底部（倍数失真场景） | 周期顶底 → 改用中周期正常化盈利 |

**降级路径**：可比法退为辅助方法，改用 rNPV（管线）/ DCF / 历史自身估值分位做主锚，并在报告**显式写明降级理由**。禁止对不适用标的硬套 comps。

### Phase 1：目标公司定位
1. 确认目标公司的行业、子行业和业务模式
2. 识别关键特征：增速、规模、盈利能力、地域、业务组合
3. 确定适用的估值指标集

### Phase 2：Comp 组选择
1. 初筛：同一子行业、类似业务模式
2. 筛选维度：
   - 收入规模（0.3x-3x 范围）
   - 增长率相似性
   - 盈利阶段（盈利 vs 亏损）
   - 地域可比性
   - 业务纯度
3. 最终选择 5-10 家最具可比性的公司
4. 对每家 comp 的选入理由做简要说明

### Phase 3：数据采集与计算
1. 采集各公司最新财务数据：
   - 市值、企业价值（EV = 市值 + 净债务 + 少数股东权益）
   - 收入、EBITDA、净利润、自由现金流
   - 增长率、利润率、ROE/ROIC
2. 计算估值倍数：
   - 历史倍数：当前年（CY）和前一年
   - 前瞻倍数：NTM（未来12个月）和下一财年
3. 计算统计量：均值、中位数、25/75 分位

### Phase 4：估值推导
1. 选择 2-3 个最适用的倍数指标
2. 确定合理倍数范围（考虑增速溢价/折价）
3. 应用于目标公司得出估值区间
4. 与当前市值对比得出隐含上行/下行空间

### Phase 5：敏感性与判断
1. 展示不同倍数假设下的估值敏感性
2. 解释溢价/折价的合理性
3. 识别 comp 组的局限性
4. 给出最终估值判断

## 注意事项

- Comp 选择需要判断力——不是同行业就一定可比，须论证选入逻辑
- 高增长公司可享受溢价，但需量化（PEG 或增速差异调整）
- 注意会计准则差异（IFRS vs GAAP vs 中国准则）对倍数的影响
- 亏损公司不适用 P/E，应使用 EV/Revenue 或 P/S
- 周期性行业注意使用中周期正常化盈利
- 标注所有数据的截至日期和来源

## 反乐观纪律（强制，估值独立性红线）

> 目的：**消除单方向偏见**（乐观或悲观）。反乐观不等于看空——机械压价和机械乐观同样不公允。下列每一条都做双向约束。

1. **对标选择**：对标组应覆盖与目标公司可比的成长区间（**含高成长与已兑现成熟同业**），避免单点锚定最乐观或最悲观一家；用中位数与 25–75 分位而非极值定价；成长性差异用 PEG / 分阶段 PS 量化调整，不因"高成长"一律给溢价、也不因"未兑现"一律折价。宁可 3 个完美 comp，不要 6 个勉强 comp。
2. **倍数取值**：倍数取对标组历史中位数（25–75 分位区间），禁止用当下情绪值/极值直接定价；若对标组整体处于情绪顶/底，参考更长历史周期或 25/75 分位而非强行中位。高增长溢价须用 PEG 或分阶段 PS 量化，不能拍脑袋加/减溢价。
3. **跨市场折溢价**：A/H/美股对标必须显式处理流动性差异折溢价（如 H 股溢价 A 股、美股流动性溢价），在估值总结中单列一栏，方向与幅度都写明依据。
4. **盈利预测独立测算优先 + 卖方锚偏差检验（2026-08-14 用户拍板）**：盈利预测**能自算的必须自算**（分部收入拆解 × 利润率假设 / 季度实际加总），自算是默认路径，让"预测怎么来的"可复现、可审计、可辩论；**算不出/数据不足才允许借用**卖方模型（一致预期/单家卖方），借用时做**偏差检验**而非统一打折——① 对比一致预期分布（多卖方离散度，判断这组卖方整体乐观还是悲观）；② 用公司指引/最新季报实际数校准（公司自述口径比卖方硬）；③ 跟踪卖方近期预测修正方向（上修/下修趋势）；④ 单一卖方时标注其立场与历史预测偏差。检验重点**不只是数字**（盈利预测数据出问题可能性小，也要验），更在**方法论层**——增长假设是否乐观线性外推（当前高增速当永续）、对标是否阶段错配（典型反面案例：2021 年券商用成熟期卡特彼勒对标成长期三一重工，得出极其乐观结论）。卖方既可能乐观也可能悲观（存在大幅下修先例），统一打折本身引入偏见。验证结论三选一：**采用 / 调整（写明依据）/ 标注 [待核]**；禁止把卖方预测直接当事实当锚。**无论自算还是借用，Phase 3 审查必查**：盈利预测来源（一致预期/单家/自主）+ 偏差检验三选一结论须显式可查。
5. **独立性自检（双向）**：目标价若显著偏离卖方目标价分布（**高于或低于中位均算**），必须写明理由（数据更新/独立测算支撑，还是锚定效应）；只质询向上偏离、不质询向下偏离同样构成偏见。评审时逐条对照。
6. **价格独立性（反锚定，2026-08-13 新增）**：目标价是"盈利 × 倍数"的基本面测算，**测算全程不得使用现价**；现价只进入"年化空间 =（目标价中值 ÷ 现价 − 1）÷ T"的分母。对比两版/两次估值时，**目标价差异只归因于盈利预测与倍数假设的差异，禁止归因于价格变动**——"股价跌了所以目标价也调低"是锚定效应，等于放弃独立估值，属硬性错误。

## 股东回报口径（分红+回购注销；股权激励作费用，2026-08-14 新增）

> 股东回报 = 真金白银流向**股东**的部分；股权激励 = 流向**员工**的稀释，两者方向相反、禁止混淆。

1. **股东回报 = 现金分红 + 回购并注销**。回购**并注销**（减少总股本）与现金分红等价，都是把公司价值归还股东（如腾讯 2024 年回购逾千亿港元且大部分注销，若只计分红会严重低估股东回报）。计算股息率 / 股东回报率 / DDM 时，回报金额须含回购注销金额，而非仅现金分红；
2. **回购不注销（转库存股用于股权激励）≠ 股东回报**——库存股最终回到市场或发给员工，不减少股本、不归还股东，只是暂时性回购，不计入股东回报（须区分"回购注销"与"回购库存股"两个动作）；
3. **股权激励（SBC，股票薪酬）作为费用从利润中扣减**——它是把利润转移给员工的股权稀释成本，非股东回报；计算真实归母利润 / 自由现金流 / 可分配利润时，须从利润中剔除 SBC（否则高估"可分配给股东的利润"，腾讯 / 阿里 / 美股科技等 SBC 占利润比重大者尤甚）。

## 幸存者终值法（深度衰退 / 困境反转行业专用，2026-08-13 新增）

> 深度衰退行业当期利润（结算滞后/减值/公允价值变动）与净资产（账面值 vs 可回收价值）均失真，PE/PB 失效。改用终局思维：锚定行业出清后的稳态，而非当期。

**公式**：企业价值 = 行业稳态市场空间 × 幸存者份额 × 稳态利润率 × 估值倍数（或稳态自由现金流折现）。

三个输入均为高难度假设，须保守口径 + 区间 + 反乐观：

1. **稳态市场空间**：可比国家经验（下行后稳态规模）+ 生理基数自下而上验算（人口/城镇化/户均），给区间不给单点；
2. **幸存者份额**：格局终局判断，须写清"为什么是它活下来"（杠杆/资产质量/融资/股东背景），禁止默认龙头通吃；
3. **稳态利润率**：用历史中枢偏下（出清后利润率中枢常下移），禁止用历史高点。

**销售口径铁律（市占率/幸存者终值法场景强制，2026-08-13 新增，2026-08-14 修正市占率口径）**：

- **市占率/行业份额**用**权益口径销售**（去重自洽）——行业销售总额（如商品房销售金额）按"每套房子一次"统计、是**去重**的；而房企"全口径签约销售"含**合作项目重复**（A 占 51% + B 占 49% 的项目，两家都算全口径 → 该销售额被重复计入），全口径市占率会高估真实份额。**市占率必须用权益口径**（克而瑞/中指"权益金额榜"有硬数据），全口径仅作"操盘规模"参考并显式标注"含合作交叉、高估真实份额"；
- **个股估值**（稳态销售 × 净利率 → 归母净利）用**权益口径销售**（对应归母净利），全口径 × 权益比 = 权益销售；归母净利是权益口径，用全口径销售直接乘净利率会高估低权益比公司；
- **两口径禁止混用**，估值表显式标注权益比（克而瑞/中指权益榜或年报硬数据优先，否则标 [估算] 并提示核实）。

**组合幸存者终值法（行业代表组合 W2 专用，2026-08-14 归位）**：

行业判断落地到组合时，把大概率活下来的幸存者当作**一个合并实体**算合计空间，**不做逐票目标价等权平均**——逐票押"谁胜出"，组合押"幸存者群体整体"，个股不确定性在组合层被分散。三点铁律：

1. **幸存者范围只进"大概率活"的核心**（纯央企/国资 + 优质民企，按"信用背书强度 + 融资成本 + 财务状况"核实），**观察档（非纯央企 + 巨亏 / 高杠杆）不进组合测算**，未覆盖标的用公开数据补；
2. **市占率严格逻辑链**——当前市占率（各家销售 ÷ 行业销售，硬数据）+ 出清转移份额（退出方份额 × 幸存者捕获比例，用龙头集中度对标 + 拿地强度佐证），**禁止直接拍单点市占率**；
3. **组合利润按业务线拆分**——开发利润 × 开发 PE + 收租/运营/代建利润 × 对应倍数，**禁止"销售 × 统一净利率"一刀切**（公司常混有商业/园区/代建/供应链等，利润率与倍数各不相同）。

**适用门禁**：仅深度衰退 / 困境反转行业（当期财报失真、格局待出清）触发；正常周期股仍走 Phase 0 ④「中周期正常化盈利」。

## 测算可复算性（敏感性表铁律，2026-08-12 新增）

1. **同一标的全套测算（敏感性表/主锚/压力测试）必须用同一股本、同一汇率换算**。全报告统一：人民币→港元 ÷0.915（1 港元≈0.915 人民币，等价 ×1.09，**只允许二选一并全文统一**）；美元收入→港元 ×7.86；A 股人民币口径不换汇（×1）。**禁止同一参数在不同表格出现不同数值**（如"60 亿×32 倍"不得既出现 46.3 又出现 50.6）。
2. **敏感性表每个格子必须能用公式复算**：数值 = 情景值 × 倍数 × 汇率 ÷ 股本。禁止手工填数、禁止表格与主锚用不同股本/不同汇率方向。
3. **表后注释必须写明公式（含汇率方向），且注释与表内数值一致**；"≈现价"类比较必须同一口径（港元对港元、人民币对人民币），禁止拿人民币数值与港元现价比。
4. **生成后必须跑审计脚本**：`scripts/recalc_sensitivity.py <报告.md>`，将"XX 行全部可复算 ✓"写入报告 QA 记录；任一不通过即修复重生成。审计脚本配置按表序与标的股本维护。

## 评级衔接（隐含回报 + 催化确定性，2026-08-12 定稿；指引层而非算法层）

> 估值产出目标价后，**接 report-skeleton「评级体系」章落评级**，作为基本面分析的收尾指引。**评级只用隐含回报 + 一句是非判断（核心催化是否必然兑现），零概率、零赔率、零加权。** 目标价一律保守口径（本技能反乐观纪律压出），**所有评级（含暂不评级）都必须给目标价**（暂不评级目标价 = "兑现情景"参考价）。

**流程（三步，非机械算法）**：

1. **目标价（保守口径）**：Phase 4/5 主锚测算结果（DCF/rNPV/正常化盈利×PE，反乐观纪律：倍数取中位数、峰值打折、低于卖方中位常态）。
2. **隐含回报 =（目标价中值 ÷ 现价 − 1）÷ T**；T = 估值兑现期（年），由估值思维决定——现值思维 T=1，终局思维 T=终局兑现年数（多方研报 + 可比经验 + 历史经验交叉确认，不好确认给范围、用保守 T 压力测试；上限 5 年，超 5 年或给不出归"无法评级"）。
3. **催化确定性**（是非判断不拍数）：核心催化是否"随时间流逝必然兑现"？
   - 已落地事实（BD 已签 / III 期已阳性 / 业绩已兑现）= **确定性高** → 按隐含回报正常评级
   - 二元事件（获批/被拒）或可能不发生的事（BD 谈判/续作）= **待催化** → 暂不评级（隐含回报 ≥25% 为**期权型**，<25% 为**待定**）

**评级落位（标准研报用语）**：≥25% 强烈推荐 | ≥10% 增持 | -5%~10% 中性 | <-5% 减持 | 目标价<现价 回避 | 待催化+隐含回报≥25% 暂不评级(期权型) | 待催化+隐含回报<25% 暂不评级(待定)。

**配套输出**：评级总览表用标准列（证券简称/代码/评级/现价/保守目标价中值/隐含回报(年化)/评级依据）；评级理由话术（考虑到【催化落地状态】；隐含回报【X%】（保守目标价中值，年化，T=Y 年）；核心催化【已落地/待落地】，给予【评级】评级）。

## 卖点测算（乐观情景参考价，与保守目标价对称的离场锚）

> 与保守目标价（买点锚）对称，补**卖点锚**：可落地乐观情景下的价值上沿，回答"涨到哪该减仓"。定义、可落地判定、触发纪律见 report-skeleton「评级体系」章「卖点」节；本技能负责其**测算口径**。

0. **适用性门禁（有意义才测）**：存在可落地乐观情景（增量催化/成长期权）才测算卖点；纯收息/成熟防御/无期权 → 不测，显式声明"无有意义的乐观情景"。与线索推演、行业空间测算门禁同源（有意义才触发，无意义显式声明）。

1. **乐观情景限定**：只取"可落地"项——已落地事实 + 有时间表/里程碑且大概率兑现（标"待落地"）；二元未决（获批/BD 谈判/续作）与纯叙事（全球 TAM/远期格局）**不计入**。
2. **中性倍数，不双倍放大**：卖点 = 可落地乐观情景盈利 × 中性倍数（历史中位/25-75 分位）。**禁止"乐观情景参数 × 乐观倍数"**——双重乐观，违反反乐观纪律；倍数仍按 Phase 0 门禁 + 反乐观纪律取。
3. **口径与可复算性同保守目标价**：同一股本、同一汇率；乐观情景敏感性表同样过 `recalc_sensitivity.py`。
4. **不改变评级**：卖点只是离场参考，评级仍由保守目标价中值算年化空间；观察档"兑现情景参考价"与卖点同口径，卖点为其上沿。
5. **输出**：估值结论并列"保守目标价中值（评级锚）"与"卖点（独立离场锚）"两档分列，不合并为区间。
