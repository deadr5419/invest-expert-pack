# 报告 PDF 排版与 QA 标准（强制执行）

> 目的：让 PDF 排版稳定可预期。排版不是事后美化，是**生成规范 + 生成后 QA 门禁**双保险。

## 〇、默认交付规则（2026-08-17 用户拍板）

- **默认产出 = MD + HTML + Word**（`共用/研报管线/md2html_full.py` / `md2docx.py`）；**PDF 仅在用户显式要求时生成**，禁止默认顺手出 PDF。
- 深度报告 PDF（封面/目录/缩进齐全）走 `共用/研报管线/md2pdf_pro.py`（xhtml2pdf）；简单版/快速 PDF 走 `共用/研报管线/generate_pdfs.py`（reportlab）。
- 所有 PDF 生成后必须过本技能 QA 门禁（§二），QA_PASS 才允许交付。
- **流水线脚本唯一主版本在 `共用/研报管线/`**（`README.md` 为总纲）；历史副本（如 `deliverables/创新药前十成份股研究/` 下同名脚本）仅供存档，禁止再引用为基准。

## 一、排版规范（生成前）

1. **表格列宽按内容分配，禁止无脑均分**：
   - 按每列内容估算宽度：中文 1.0 字宽、ASCII/数字 0.55 字宽，取"表头+所有行"的最大值按比例分配
   - 设列宽钳制：窄列 min 1.6cm（代码/权重/数字），宽列 max 5.2cm（一句话/依据/说明）
   - 列数 > 6：压缩内容或拆表，避免单列过窄
2. **单元格必须用 Paragraph**（自动换行）；连续英文/数字串允许断行（splitLongWords=1），防溢出
3. **表头深底白字、左对齐**（与数据单元格统一，避免短词悬空）；行交替白/浅灰（便于阅读）
4. **中文段落一律 TA_LEFT（绝对禁止 TA_JUSTIFY）**：JUSTIFY 会强制拉伸中文字距产生"散开/平铺"感（中文无空格做对齐调节），左对齐字距均匀最自然
5. **一页纸目标 1 页**：溢出先启用 compact 模式（body 8.0/行距 12/表 6.8/padding 2/边距 1.3×1.1cm）；仍溢出则删表列/精简文字，禁止"差不多就行"
6. **中文字体覆盖**：SimHei + MSYH 必须注册；`→ × ± ① ② ③` 等符号确认不显示方框
7. **分页**：`PageBreak` 只在第二个及以后的 H1 前加（首个 H1 不加，防封面/一页纸后空白页）；TOC 页后保留一个 PageBreak
8. **封面/目录格式（xhtml2pdf 管线，2026-08-13 新增）**：走 `md2pdf_pro` 时，封面必须用**元信息格式**——`# 系列名` + `## 报告标题` + `> 数据快照/署名/免责声明`；**禁止表格封面**（`## 封面页` + 表格会被 parse_cover 误判，致封面 title 错显、目录页空，腾讯 Pro 版教训）。目录用 `## 目录` + 章节列表，供 split_body 解析。

## 二、生成后 QA 门禁（必须执行，类比代码 CI）

**优先用自动化审计脚本 `qa_check.py`**（主版本：`共用/研报管线/qa_check.py`，2026-08-17 起为唯一基准；`generate_pdfs.py` / `md2pdf_pro.py` 生成后自动调用，输出 `QA_PASS` 才允许交付）。敏感性审计传参：`--config "名称,股本,单位"`（CNY/HKD/USD）。脚本落地以下检查：

| 检查项 | 方法 | 通过标准 |
|---|---|---|
| 页数 | `doc.page_count` | 一页纸 == 1 页；深度报告在预期范围 |
| 溢出 | 每页 `get_text('blocks')` 最低 y（**先排除页脚区 y>800**，页脚在页底约 y=815 属正常） | 正文内容最低 y < 800 |
| 表格竖线 | `get_drawings()` 提取竖线 | 列数与设计一致、无列重叠 |
| 文字截断/越界 | 逐块检查 `x1` 是否超出页面宽−右边距（容差 8pt） | 无文本越出页面右边距 |
| 乱码 | ①源 MD 非 GBK 字符扫描（emoji ✅❌⚠ 等，STSong-Light 只覆盖 GBK→方框；md2pdf_pro 已内置 sanitize_gbk 兜底替换 √×△）；②全文检查 **U+25A1(□) / U+FFFD(�)** | 无字体缺失方框；⚠️ 汉字"口"(U+53E3)是正常字符，**禁止**用"口"字检测（2026-08-12 实测误报教训） |
| 空白页 | 逐页统计 y<800 的文本块 | 每页至少 1 个正文块（封面/目录后的多余 PageBreak 即此类） |
| 敏感性可复算 | `qa_check.py --md` 解析深度报告全部敏感性表，逐格复算 数值=情景×倍数×汇率÷股本 | 全部可复算 ✓（与 comps-valuation 审计脚本同口径） |

**抽检渲染**：封面、评级总览表、每章首页各渲染 1 张 PNG 目检。

## 三、常见问题与修复表

| 问题 | 根因 | 修复 |
|---|---|---|
| 一页纸溢出 2 页 | 内容多/字号大 | compact 模式 → 仍溢出则删列/精简 |
| 表格列太窄折行乱 | 列宽均分 | 按内容分配列宽（本技能规范一.1） |
| 表格超页宽/文字截断 | 表太宽/列太多 | 压缩列宽、拆表 |
| 乱码方框 | ①字体未注册；②源 MD 含非 GBK 字符（emoji） | ①检查 SimHei/MSYH TTFont 注册；②源 MD 非 GBK 字符替换（✅→√ 等）或走 md2pdf_pro 的 sanitize_gbk 兜底；检测用 U+25A1/U+FFFD 而非汉字"口" |
| 封面/目录后空白页 | 首个 H1 前误加 PageBreak | 首个 H1 不加分页（规范一.6） |
| 文字压到页脚 | 边距/内容过长 | 调整边距或精简，或换页 |

## 四、与 report-skeleton 联动

- `report-skeleton` 的 W1/W2 模板"产出要求"已强制加载本技能
- 研深行产出 Markdown 时不承担排版；主任转 PDF 时执行本技能规范 + QA 门禁
- 排版问题定位顺序：先查规范一（列宽/compact/分页），再查 QA 门禁项，修完重生成重检
