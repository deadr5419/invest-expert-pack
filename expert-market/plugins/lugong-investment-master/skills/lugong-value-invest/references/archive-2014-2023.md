# 存量核心观点原典（2014–2023 资料集精华）

> 来源：《超级鹿鼎公资料集（2014-2023）》OCR 精读（2026-08-06）。**观点框架，非既定事实；OCR 有错字，引用重要数据请对照原书。**

## A1 价值之锚方法论（2015-07-13 深读原文）

- **股票的底线/底锚**："未来业绩没有大幅度下降预期的 8-9% 现金分红价，就是股价的底锚。不信你去看看历史，几乎所有的好股票，即使在最烂的大熊市，都在这个区域之前构筑成底部（华能如此，上汽也是如此，银行也是一样）"
- **分红率规则**："高于40%分红率的按实际分红率计算，低于40%的分红率，按每股盈利的40%计算"
- **水电特殊处理**："水电行业的巨大现金流是其他行业无法比拟的……俺个人设定川投的分红不是以实际分红计算的，而是按照现金流的50%（也就是盈利的65%）计算"——当年川投价值之锚设定在 7.20 元附近；工行价值之锚在 3.52 元附近
- **搬砖之锚**（估值差套利阈值）："俺个人设定的招行与兴业的最大估值差25%，这个是我个人完全无法忍受的估值差——5%轻松忍受，10%有点心动，15%肯定搬点，20%拿点高估等风，25%无法忍受抛弃高估"
- **锚的哲学**："所有的价值之锚都是极端情况下的预估，欲胜敌，先为不可胜，以待敌之可胜。我们只要心中有底，就不会被恐惧吓倒，越靠近底部越有勇气。但是千万别刻舟求剑……只要在买进的时候做好万一到达价值之锚的时候的对策，俺的买卖逻辑就建立了"
- 问答补充：底锚=按"未来业绩不增长且分红后"计算的股价；无风险利率下降周期分红价锚会越来越低（"现在有6%就好"）
- 分级A案例：3+分级A票面3%，0.65元时实际利率5%+45%下折收益年化5%=年化10%→"到了0.65元，俺真的会卖房子上"

## A2 好股票的四个条件（2019-03-28 深读）

1. **天然的垄断性**：市场垄断（茅台）、资源垄断（长江电力）、技术垄断（高通、恒瑞）、上下游贯通垄断（海螺）、多因素复合垄断（神华、阿里巴巴）→ 高毛利、高现金流
2. **前景良好**：未来业绩不会大幅度跳动（正常波动可接受）
3. **低的估值**："投资的长期收益是在你买入那一瞬间就已经决定……低估值的买入确保你的最低收益，10PE的长电，大概率是不会输钱的"
4. **成长的空间**：行业空间深度+竞争力（肺癌药必然比渐冻症药更有空间；收入增长期的房产比增速接近0的更有上涨空间）

## A3 垄断才是长期高额利润的基础（2019-05-21 深读）

- 原话："不管怎么样的公司，只要是能够长期赚取高额利润的，无一不是垄断"
- 分类：市场型（茅台/可口可乐，市占率超41%不犯错很难败）、技术型（苹果/专利）、寡头型（格力美的——最怕行业天花板后寡头互相绞杀）、资源型（长电/黔源/两投，占山为王占江为王）、矿产型+成本型（神华煤电港路一体化、陕煤）
- 持久性："一时的领先并不难，难的是长期垄断"——最易保持：资源型、市场型（不可复制，被打破往往是行业被颠覆：核聚变取代煤炭、方便面被健康饮食取代、柯达被数码相机）；技术垄断易破（诺基亚、韩系内存、隆基金刚线）；最难攻克的是专利垄断（医药基本保证20年收益）
- **垄断需要定价权**："垄断需要有定价权，失去定价权，就要根据定价来看估值。煤炭、水电、高速同理，因为没有定价权，所以长期被市场低估"
- **神华H vs 中海油H**（2019 问答）：都是能源股都低估值；神华产品折价销售、海油产品市价销售；估值差异三因素：①海油产品价格波动大 ②分红率差异+海油H股分红税率28% ③神华业务在国内安全性高不少
- 降息逻辑（2019-07）：高确定性高分红行业龙头估值有提升空间（尤其降息背景）；高负债龙头降息中财务成本下降→盈利增加→交易性机会

## A4 做T的态度（2019-03-23 深读）——修正认知

- 原话："做T是有天赋的职业选手一项重要的辅助工具，类似职业选手的工资收入。对于普通投资者，没有一定天赋和技术水平的投资者并不适合"
- 三个理由：①金额小成本大（5000块要0.3%才能打平，3万元只要0.15%）②做T需要大量时间盯盘 ③需要良好的技术分析能力和心理素质、对股票股性很熟悉
- "我所认识的职业高手中，几乎超过50%都是做T高手……所以我可以做的，并不代表你可以做，**普通投资者最重要的是选股能力和仓位控制能力**，认识得到计算得出股票本身的价值，高位敢于出货，低位敢于拿货"
- 持股集中度原话（2019-03-23）："我的持股集中吗？是的，很集中，一共才4只股票，还是长期持有。我的持股分散吗？是的，很分散——一只深市A股中小板，一只沪市A股大盘股，一只B股，一只港股，4只股票在4个市场"

## A5 完美的底部（2018-08-08 深读原文）

- 抄底信号："股价和估值都很低 + 企业经营良好 + 经济转好 + 货币宽松 + 分红很高 + 成交量大幅度缩量 + 市场成交萎靡没人愿意卖票 + 市场没有任何获利盘 + 大批大股东也看不下去纷纷开始回购"
- "所以，在任何时候，都不可能出现完美的底部，等着你来抄底（如果这世界上有完美底部的话，我觉得也就只有1932年-1933年美国道琼斯）"
- "预测不重要，应对策略才重要"——"一定要按照既定策略去执行到底，不要被套了跌了10%就吓坏了扛不住了"
- 反面案例（2004年）：卖掉持有6年的格力电器换成更低风险的基金景博，"被扇了这辈子在股市上最大最响亮的一记耳光"
- "要有一颗资产的心"（铁帮主）：选择一份好资产，低价买入，哪怕被套，卧倒装死，坚定持有，最终也会赚大钱
- 道术三问："1是不是真的是好资产；2是不是真的低估值；3能不能坚定持有。这才是道，做差价看技术都只是术"

## A6 茅台数学题（2023-09-23 深读）——盈利推演框架

- 22年营收1275亿、利润627亿（利润正好是营收的一半）；直销营收495亿
- 过去10年利润增长370%（年化16.8%）；产能5.68万吨（2012年3.3万吨，10年+72%）
- 22年EPS 50元，按15%增长10年→EPS 200元、全年利润3100亿、营收超5000亿（主要靠涨价）
- 假设全直销（770亿转直销）→增加380亿利润正好1000亿；假设出厂价1499翻倍到3000→利润2000亿；假设产量再+72%→3400亿利润
- 抛给市场的问题："10年后茅台卖多少钱一瓶？5000元？还是6000元？"
- 巴菲特PE纪律（2023-11-07）："巴菲特买可口可乐是14PE，买喜诗糖果12PE，买的苹果11PE，买西方石油9PE，你见过巴菲特用30PE买股票吗，更不要说40PE"

## A7 高风险与低风险是相对的（2015-06-14 深读）

13组相对论对比（节选）：100万资产买100万股票=高风险 vs 500万买100万=低风险；高估值=高风险 vs 低估值=低风险；常常满仓=高风险 vs 常备现金永不满仓=低风险；全仓一只=高风险 vs 全仓一个组合=低风险；满仓杠杆=高风险 vs 永不融资=低风险；没有现金流却上50%杠杆=高风险 vs 满仓杠杆但有其他现金流保护=低风险；满仓高位热门股票=高风险 vs 满仓高位热门但有极快割肉刀=低风险
- 结论："所谓高风险低风险都是相对个人情况而言，有多大能力吃多少饭，关键在于你对于自身能力的认知，并且知行合一"
- "人们最常犯的错误就是对自己能力的认识，这个才是成功的大敌。人们最容易失败的心魔，就是对胜利的渴望远大过对失败的恐惧"
- 1995年教训（2015-07-09）：6.4万小资金（同时期杭州城西40方房产）被爆仓一场——"让俺谨慎，让俺记住教训，一辈子牢记风险，牢记安全第一，确定性第一"

## A8 银行研究六个角度（2018-08-31 深读）——方法论原典

1. **坏账要还原数据看**："应该把核销掉的数据也拿回来，否则你看不清真实发生数据"
2. **ROA视角**："资产增速14%但利润增速0-5%，说明ROA下降10%以上，垫进去的资本都是无效资本——靠扩大规模顶住了利润下滑，但规模能永续扩张吗"
3. **债券浮赢陷阱**："债券狂涨造成银行巨额浮赢，但这个盈利可持续吗？明年就打回原形吧"
4. **庞然大物论**："银行坏账组成基本是几千万几亿的中小企业，庞然大物（龙煤、渤海钢铁、中建材、中远、中钢）不倒几家，俺个人不会认定坏账率见顶"
5. **利差对比法**："每份年报/半年报都有平均存款利率和平均贷款利率，拿出来跟往年比，就是利差对比"
6. **M2谬论**："M2增速高银行利润就增加"不成立——日本M2增速一直不高但一直在增加，银行利润增加了吗
- **工行风控原话**（2018-10-16）："工行自从姜董离开之后，风控水平一落千丈——13、14年我在垃圾企业的融资数据中基本上看不到工行占据融资金额前5，但姜董离开后的工行，垃圾企业融资银行金额前三名中总是看到工行"
- 坏账消化论反驳："当年工行25%的坏账不也消化了吗——问题是那时候是中国经济高速发展期，通胀也足够，现在能跟那时候比吗"
- 日本台湾银行业参照："日本500强前10名银行占好几个名额，现在最高的住友金融排名209"
- 杠杆倍数："其他行业最多2倍杠杆，银行是8-10倍，高杠杆的银行经不起大的经济波动"
- 银行出货纪律（2015）："不看15PE以上，打提前量，10PE开始分批出货"
- 银行观点演进注：2015-2018 他系统看空银行（"中短期一定会有不少非常巨大的地雷，我看不清所以不敢投"），与其 2014 年重仓建行工行形成时期差异——详见 timeline

## A9 其他存量要点

- **万科/高杠杆**（2023-11-07）："万科之所以有危机，主要原因就是他在一个高杠杆行业，流动性危机并不一定需要经营亏损，就可能发生"
- 白酒零售价逻辑（2024 补充）："五粮液零售价900多跟不住茅台，因为副产品多（中低端酒占比高），高端白酒靠主流品种赚钱补贴其他品种，主流品相补贴不动的时候就是零售价见顶的表现"
